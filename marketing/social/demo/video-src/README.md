# เครื่องเรนเดอร์คลิปสอน → MP4

ทำคลิปสอนแบบแอนิเมชันออกมาเป็นไฟล์ MP4 9:16 พร้อมโพสต์ **ในเครื่องตัวเอง ไม่ต้องสมัครบริการอะไร ไม่ต้องติดตั้ง npm**

| ไฟล์ | หน้าที่ |
|---|---|
| `lesson-borrow.html` | ภาพทั้งคลิป เขียนเป็น `drawAt(t)` บน canvas 1080×1920 — ทุกอย่างเป็นฟังก์ชันของเวลา เรนเดอร์ซ้ำได้ภาพเดิมเป๊ะ |
| `capture.mjs` | สั่ง Chrome headless ผ่าน CDP ให้วาดทีละเฟรมแล้วถ่ายภาพ (ใช้ WebSocket/fetch ที่มากับ Node 22+) |
| `assets/kao-*.png` | ครูเก้า ตัดจาก `marketing/video/characters/kru-kao.png` — ท่าฮีโร่ (ฮุก) · ท่ากอดอก (ปิดท้าย) · หน้า (ตราในหัวคลิป) |

## สั่งเรนเดอร์

```bash
node capture.mjs "%TEMP%/frames" 30
```

```bash
ffmpeg -y -framerate 30 -i "%TEMP%/frames/f%05d.png" -f lavfi -i anullsrc=channel_layout=stereo:sample_rate=48000 -c:v libx264 -preset slow -crf 19 -pix_fmt yuv420p -c:a aac -b:a 96k -shortest -movflags +faststart out.mp4
```

ตรวจหน้าตาก่อนเรนเดอร์เต็ม (ได้ 8 ภาพจาก 8 จังหวะ ใช้เวลา ~5 วินาที):

```bash
node capture.mjs "%TEMP%/probe" 30 probe
```

**ของที่ต้องมีในเครื่อง:** Node 22+ · Chrome หรือ Edge · ffmpeg — มีครบแล้วในเครื่องนี้
คลิป 31 วินาที = 930 เฟรม ใช้เวลาเรนเดอร์ ~8 นาที ได้ไฟล์ ~2.4 MB

## ทำคลิปตอนต่อไป

ก๊อป `lesson-borrow.html` เป็นไฟล์ใหม่ แล้วแก้ 2 จุด

1. **`BEATS`** — บทพูด/ซับไทเทิลของแต่ละจังหวะ กับความยาว (มิลลิวินาที) · ขั้นละ 1 ประโยค ตามกฎใน [VIDEO_GUIDE.md](../../VIDEO_GUIDE.md)
2. **ฟังก์ชันวาด** (`racks` `ones` `tally`) — เปลี่ยนตามภาพของบทเรียนนั้น

เปลี่ยนวิชา = เปลี่ยนรูปใน `assets/` เป็นครูคนนั้น (ครูจัน ไทย · ครูมายด์ อังกฤษ · ดร.ภู วิทย์) แล้วเปลี่ยนสีโคมใน `C.blue`

สิ่งที่ไม่ต้องแตะ: พื้นหลัง หัวคลิป กล่องซับไทเทิล แถบเวลา เขตปลอดภัย โครง 3 องก์ — ใช้ซ้ำได้ทั้งชุด คลิปทุกตอนจึงหน้าตาเป็นแบรนด์เดียวกัน

### บทเรียนจากการทำรอบแรก

- **อย่าทาสีพื้นหลังทับขอบรูปเพื่อให้กลืน** — ยังไงก็เห็นเป็นกรอบสี่เหลี่ยม เพราะสีที่ทาไม่ตรงกับฉากข้างหลังเป๊ะ ต้องลบขอบให้โปร่งจริงด้วย `destination-out` (ดูฟังก์ชัน `featheredImage`)
- **`glowDot` ต้องคูณ `globalAlpha` ไม่ใช่ทับ** ไม่งั้นของที่สั่งให้จางหายจะจางแค่กรอบ ส่วนไฟข้างในค้างอยู่
- **รันโหมด `probe` ดูภาพก่อนทุกครั้ง** — เรนเดอร์เต็มใช้ 8 นาที แต่ probe ใช้ 5 วินาที

## กติกาที่ฝังไว้ในไฟล์แล้ว

- **9:16 · 1080×1920 · 30fps** และมีแทร็กเสียงเงียบติดมาด้วย (บางแพลตฟอร์มงอแงถ้าไม่มีแทร็กเสียง)
- **เขตปลอดภัย** ไม่มีอะไรสำคัญอยู่ใน 15% บน และ 20% ล่าง (แถบเวลาเส้นล่างสุดเป็นของประดับ ไม่เป็นไรถ้าโดนบัง)
- **ซับไทเทิลเผาติดภาพทุกเฟรม** — คนส่วนใหญ่ดูแบบปิดเสียง
- **ตัวหนังสือเป็นโค้ด ไม่ใช่ภาพ AI** จึงสะกดไทยถูกทุกคำ และเปลี่ยนโจทย์/เบอร์โทรได้โดยไม่ต้องสั่งภาพใหม่
- **โลกโคมไฟ** ตาม [docs/CHARACTER_SHEET.md](../../../../docs/CHARACTER_SHEET.md) — คณิต = โคมน้ำเงิน (ครูเก้า) · ความรู้ = แสง
