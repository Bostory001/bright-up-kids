# เครื่องเรนเดอร์คลิปสอน → MP4

ทำคลิปสอนแบบแอนิเมชันออกมาเป็นไฟล์ MP4 9:16 พร้อมโพสต์ **ในเครื่องตัวเอง ไม่ต้องสมัครบริการอะไร ไม่ต้องติดตั้ง npm**

| ไฟล์ | หน้าที่ |
|---|---|
| `capture.mjs` | สั่ง Chrome headless ผ่าน CDP ให้วาดทีละเฟรมแล้วถ่ายภาพ (ใช้ WebSocket/fetch ที่มากับ Node 22+) |
| `lesson-borrow.html` | **คลิปสอน #1** ลบแบบมีการกระจาย (52 − 7) · 31 วิ |
| `lesson-wordproblem.html` | **คลิปสอน #2** โจทย์ปัญหา จะ + หรือ − · 32 วิ · มีชุดเอฟเฟกต์ |
| `assets/kao-*.png` | ครูเก้า ตัดจาก `marketing/video/characters/kru-kao.png` — ท่าฮีโร่ (ฮุก) · ท่ากอดอก (ปิดท้าย) · หน้า (ตราในหัวคลิป) |

แต่ละคลิปเป็นไฟล์ HTML ไฟล์เดียวที่ประกาศ 3 อย่างให้ `capture.mjs` เรียก: `drawAt(t)` · `TOTAL_MS` · `PROBE_MS`
ทุกอย่างเป็นฟังก์ชันของเวลา จึงเรนเดอร์ซ้ำกี่รอบก็ได้ภาพเดิมเป๊ะ

## สั่งเรนเดอร์

ตรวจหน้าตาก่อนเสมอ — ได้ 8 ภาพจาก 8 จังหวะ (เวลาที่ถ่ายกำหนดไว้ใน `PROBE_MS` ของแต่ละคลิป) ใช้เวลา ~5 วินาที:

```bash
node capture.mjs --page=lesson-wordproblem.html "%TEMP%/probe" 30 probe
```

```bash
node capture.mjs --page=lesson-wordproblem.html "%TEMP%/frames" 30
```

```bash
ffmpeg -y -framerate 30 -i "%TEMP%/frames/f%05d.png" -f lavfi -i anullsrc=channel_layout=stereo:sample_rate=48000 -c:v libx264 -preset slow -crf 19 -pix_fmt yuv420p -profile:v high -level 4.0 -c:a aac -b:a 96k -shortest -movflags +faststart out.mp4
```

ไม่ใส่ `--page=` จะเรนเดอร์ `lesson-borrow.html` (คลิป #1)

**ของที่ต้องมีในเครื่อง:** Node 22+ · Chrome หรือ Edge · ffmpeg — มีครบแล้วในเครื่องนี้
คลิป 32 วินาที = 960 เฟรม ใช้เวลาเรนเดอร์ ~9 นาที ได้ไฟล์ ~2.5 MB

## ทำคลิปตอนต่อไป

ก๊อปคลิปที่โครงใกล้เคียงที่สุดเป็นไฟล์ใหม่ แล้วแก้ 3 จุด

1. **`BEATS`** — บทพูด/ซับไทเทิลของแต่ละจังหวะ กับความยาว (มิลลิวินาที) · ขั้นละ 1 ประโยค ตามกฎใน [VIDEO_GUIDE.md](../../VIDEO_GUIDE.md)
2. **`PROBE_MS`** — 8 เวลาที่จะถ่ายมาตรวจ เลือกจุดที่ของในจังหวะนั้นขึ้นครบแล้ว
3. **ฟังก์ชันวาดกลางจอ** — ของคลิป #1 คือ `racks` `ones` `tally` · ของคลิป #2 คือ `boxDiagram` `problemCard` `ruleCard` `eqZone`

เปลี่ยนวิชา = เปลี่ยนรูปใน `assets/` เป็นครูคนนั้น (ครูจัน ไทย · ครูมายด์ อังกฤษ · ดร.ภู วิทย์) แล้วเปลี่ยนสีโคมใน `C.blue`

สิ่งที่ไม่ต้องแตะ: พื้นหลัง หัวคลิป กล่องซับไทเทิล แถบเวลา เขตปลอดภัย โครง 3 องก์ `featheredImage` `fitText` — ใช้ซ้ำได้ทั้งชุด คลิปทุกตอนจึงหน้าตาเป็นแบรนด์เดียวกัน

### ชุดเอฟเฟกต์ (อยู่ในคลิป #2 ใช้ซ้ำได้)

ฟังก์ชันอยู่ติดกันในบล็อก "เอฟเฟกต์" ก๊อปไปใช้ได้ทั้งก้อน

| เอฟเฟกต์ | ฟังก์ชัน | ใช้ตอนไหน |
|---|---|---|
| blade slice | `bladeSlice` | ผ่าของชิ้นเดียวให้แยกเป็นสองชิ้น |
| orbit ring | `orbitRing` | ล้อมของที่อยากให้คนดูมอง (วาดครึ่งหลังก่อน ครึ่งหน้าทับ) |
| impact frame | `impactFlash` `shockwave` | จังหวะเฉลย |
| paper tear | `renderCard` `tearPiece` | ทิ้งการ์ดเก่าก่อนขึ้นการ์ดใหม่ |
| blow away | `blowAway` | เศษปลิวตามหลังการฉีก |
| letter dive | ในตัว `hookFrame` | หัวเรื่องตกลงมาทีละคำ |
| rack focus | `g.filter = "blur(...)"` ใน `boxDiagram` | ดันของเก่าไปเป็นฉากหลัง |
| dolly zoom | ในตัว `background` | ฉากหลังถอยตอนปิดท้าย |

**กติกาที่ตั้งไว้** — ใส่เอฟเฟกต์เฉพาะที่ช่วยเล่าเนื้อหา ไม่ใช่เพราะมันสวย
เอฟเฟกต์สายเทค/สายการเงิน (banknote, code body, post wall, comment drop, predict keys, live cursor)
ไม่เข้ากับบทเรียน ป.2 ใส่แล้วจะกลายเป็นรีลโชว์เอฟเฟกต์

### บทเรียนจากรอบที่ผ่านมา

- **อย่าทาสีพื้นหลังทับขอบรูปเพื่อให้กลืน** — ยังไงก็เห็นเป็นกรอบสี่เหลี่ยม เพราะสีที่ทาไม่ตรงกับฉากข้างหลังเป๊ะ ต้องลบขอบให้โปร่งจริงด้วย `destination-out` (ดูฟังก์ชัน `featheredImage`)
- **`glowDot` ต้องคูณ `globalAlpha` ไม่ใช่ทับ** ไม่งั้นของที่สั่งให้จางหายจะจางแค่กรอบ ส่วนไฟข้างในค้างอยู่
- **ของจังหวะก่อนต้องสั่งให้จางหายเอง** — คลิป #2 รอบแรก คำตอบ `15 + 8 = 23` ค้างอยู่ใต้โจทย์ข้อใหม่ เพราะเงื่อนไขครอบช่วงเวลากว้างเกินไป
- **ข้อความไทยตัดบรรทัดอัตโนมัติไม่ได้** (ไม่มีช่องว่างระหว่างคำ) จึงต้องเขียนบทให้สั้นพอ และให้ `fitText` ย่อฟอนต์กันล้นกรอบไว้อีกชั้น
- **แฟลชอย่าทาขาวทับทั้งจอ** — บนฉากกลางคืนจะได้ภาพสีเทาซีดเหมือนไฟล์เสีย ไม่ใช่แสงกระแทก ต้องใช้ `globalCompositeOperation = "lighter"` ยิงแสงอุ่นออกจากจุดที่เฉลย
- **แฟลชทั้งคลิปห้ามถี่เกิน 3 ครั้งต่อวินาที** เป็นความเสี่ยงกับคนแพ้แสงกะพริบ คลิป #2 มี 2 ครั้ง ห่างกัน 11 วินาที
- **รันโหมด `probe` ดูภาพก่อนทุกครั้ง** — เรนเดอร์เต็มใช้ 9–11 นาที แต่ probe ใช้ 5 วินาที

## กติกาที่ฝังไว้ในไฟล์แล้ว

- **9:16 · 1080×1920 · 30fps** และมีแทร็กเสียงเงียบติดมาด้วย (บางแพลตฟอร์มงอแงถ้าไม่มีแทร็กเสียง)
- **เขตปลอดภัย** ไม่มีอะไรสำคัญอยู่ใน 15% บน และ 20% ล่าง (แถบเวลาเส้นล่างสุดเป็นของประดับ ไม่เป็นไรถ้าโดนบัง)
- **ซับไทเทิลเผาติดภาพทุกเฟรม** — คนส่วนใหญ่ดูแบบปิดเสียง

- **โจทย์แต่งเองทุกข้อ** ไม่ได้คัดลอกจากเอกสาร HQ หรือหนังสือแบบฝึกหัดอื่น (ดู "ข้อจำกัดจากแฟรนไชส์" ใน CLAUDE.md)
