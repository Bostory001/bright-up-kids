# คลิปสอน #2 — เวอร์ชัน HyperFrames

คลิปเดียวกับ `../lesson-wordproblem-fx-1080x1920.mp4` แต่ทำด้วย [HyperFrames](https://github.com/heygen-com/hyperframes) แทนเครื่องเรนเดอร์ canvas ที่เขียนเอง — ทำไว้เทียบกันว่าควรย้ายมาทางนี้ไหม

## สั่งงาน

```bash
node tools/build-index.mjs
```

```bash
npm run check
```

```bash
npm run dev
```

```bash
npm run render
```

`build-index.mjs` คายไฟล์ `index.html` ออกมา · `check` คือตัวตรวจสัญญา (เขตปลอดภัย คอนทราสต์ ขนาดตัวหนังสือ) · `dev` เปิด Studio ให้**แก้คำพูดกับจังหวะเองได้ในเบราว์เซอร์** · `render` ออกเป็น MP4

ไม่ต้อง `npm install` — ทุกคำสั่งเรียกผ่าน `npx hyperframes@0.9.31`

## ทำไมถึงมีตัวเขียนไฟล์ (`tools/build-index.mjs`)

ของประดับที่ซ้ำ ๆ (โบเก้ 10 ชิ้น เศษกระดาษ 26 ชิ้น จุดบอกขั้น 8 จุด ซับ 8 จังหวะ) พิมพ์มือแล้วแก้ยาก
สคริปต์คายออกมาเป็นแท็กจริงในไฟล์ ไม่ได้สร้างตอนรัน — Studio จึงยังแก้ได้ตามสัญญาของ HyperFrames

**แก้บทพูด/จังหวะ** ที่ `BEATS` ในสคริปต์แล้วรัน `build-index.mjs` ใหม่ หรือแก้ใน Studio ตรง ๆ ก็ได้ (ถ้าแก้ใน Studio อย่ารัน build ทับ)

## ฟอนต์ไทย

HyperFrames ห้ามต่อเน็ตตอนเรนเดอร์ และชุดฟอนต์ที่ให้มามีแต่ภาษาละติน
`assets/fonts/` จึงเก็บ Bai Jamjuree + IBM Plex Sans Thai เป็น woff2 ไว้ในเครื่อง (20 ไฟล์)
`faces.css` คือ CSS ของ Google Fonts ที่เปลี่ยน URL เป็นพาธในโปรเจกต์แล้ว และถูกฝังลงใน `index.html`

โหลดใหม่ได้ด้วยสคริปต์ใน git log (commit ที่เพิ่มโฟลเดอร์นี้)

## สิ่งที่ตัวตรวจจับได้ และเวอร์ชัน canvas พลาดไว้

| ข้อ | ที่แก้ |
|---|---|
| `#tsub` คอนทราสต์ 1.4:1 ต้องการ 3:1 | ช่วงฮุกมีภาพครูสว่างอยู่หลังหัวคลิป ตัวหนังสือจม → เพิ่ม `#headscrim` ไล่สีบัง |
| `#addr` คอนทราสต์ 2.21:1 | บรรทัดที่อยู่จางเกินไป → ขึ้นเป็น 72% |
| `text_below_floor` | ป้าย "ทั้งหมด"/"ส่วนย่อย" 26px ต่ำกว่าพื้น 28px ที่อ่านออกบนมือถือ → ขยายเป็น 28px |
| `panel_out_of_canvas` | `#bgtop` ล้นขอบบนโดยตั้งใจ → ใส่ `data-layout-allow-overflow` |

หลังแก้: **คอนทราสต์ผ่าน WCAG AA 54/54 · เลย์เอาต์ 0 ปัญหา**

สามข้อแรกมีอยู่ในคลิปเวอร์ชัน canvas ด้วย แค่ไม่มีใครตรวจ

## ที่ยังเตือนอยู่ และจงใจปล่อย

- `film_silent` — ยังไม่มีเสียงตามแผน VIDEO_GUIDE กำหนดให้ใช้เสียงจริงของครู อัดทับทีหลัง
- `nested_structure_needs_subcomposition` 18 จุด — HyperFrames อยากให้แยกแต่ละฉากเป็นไฟล์ย่อย จะได้แก้ใน Studio ง่ายขึ้น ยังไม่ทำเพราะคลิปเดียวยังไม่คุ้ม ถ้าทำตอนต่อ ๆ ไปค่อยแยก
