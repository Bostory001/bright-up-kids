# บทพากย์คลิปสอน

บทสำหรับอัดเสียงหรือสังเคราะห์ด้วย VoxCPM2 · **ไม่ใช่ข้อความซับไทเทิล**
ซับบนจอสั้นกว่านี้เพราะต้องจบในบรรทัดเดียว ส่วนบทพูดเขียนให้ฟังแล้วเป็นธรรมชาติ

## กติกาการเขียนบทพูด

- **เขียนตัวเลขเป็นคำอ่านทั้งหมด** ปล่อยเลขอารบิกไว้โมเดลจะอ่านมั่ว และคนอ่านก็สะดุด
- หนึ่งจังหวะ หนึ่งความคิด ไม่ซ้อนประโยค
- ลงท้าย "ครับ/ค่ะ" เฉพาะจังหวะที่คุยกับพ่อแม่ตรง ๆ ไม่ใช่ทุกประโยค
- ห้ามสัญญาผลการเรียนที่ HQ ยังไม่ได้รับรอง

## ไฟล์เสียงต้องชื่ออะไร

วางที่ `<โปรเจกต์คลิป>/assets/vo/` ตั้งชื่อ `b0.wav` `b1.wav` … ตามเลขจังหวะในตารางข้างล่าง
สเปกเดียวกับคลังเสียง: **48 kHz โมโน 16 บิต ตัดเงียบหัวท้าย ห้ามมีดนตรีคลอ**

พอครบแล้วสคริปต์จะวัดความยาวจริงเขียนลง `timing.json` แล้วจังหวะภาพจะยืด/หดตามเสียง
ไม่ต้องอัดให้พอดีกับเวลาที่ตั้งไว้ อัดให้เป็นธรรมชาติพอ

สังเคราะห์ใหม่เฉพาะประโยคเดียว:


# คลิป #2 · โจทย์ปัญหา จะบวกหรือลบ — **บทพร้อม แต่ภาพต้องทำใหม่ก่อน**

เนื้อหายังดีอยู่ กล่องส่วนย่อย–ทั้งหมดใช้ได้ **แต่ภาพยังเป็นโลกโคมไฟกลางคืนที่ไม่เอาแล้ว**
ถ้าอัดตอนนี้แล้วภายหลังทำภาพใหม่ จังหวะอาจไม่ตรง — แนะนำให้ทำภาพเป็นธีมเพจก่อน

| 0 | ลูกบวกลบเลขคล่อง แต่พอเจอโจทย์ปัญหาแล้วนิ่งเลยใช่ไหมครับ | 2.9 วิ |
| 1 | อย่าเดาจากคำว่ารวมหรือเหลือนะครับ ให้วาดกล่องนี้ก่อน | 3.8 วิ |
| 2 | เลขที่โจทย์บอกมา ใส่ลงช่องเล็กสองช่อง ช่องใหญ่ยังว่างอยู่ | 4.6 วิ |
| 3 | ช่องใหญ่ว่าง แปลว่าโจทย์ถามหาทั้งหมด หาทั้งหมดต้องบวก สิบห้าบวกแปดเท่ากับยี่สิบสาม | 4.0 วิ |

| 5 | ช่องเล็กว่าง แปลว่าหาส่วนย่อย หาส่วนย่อยต้องลบ ยี่สิบสามลบสิบห้าเท่ากับแปด | 4.2 วิ |
| 6 | กล่องเดียวใช้ได้ทุกโจทย์ ไม่ต้องเดาคำในโจทย์อีกแล้ว | 3.6 วิ |

# คลิป #1 · ลบแบบมีการกระจาย — **ยังไม่ต้องอัด**

ไม่ใช่แค่ภาพที่ต้องเปลี่ยน **ตัวบทเรียนสร้างอยู่บนอุปมาโคมไฟทั้งอัน**
"โคมสิบ" คือหลักสิบ "โคมหนึ่ง" คือหลักหน่วย ยืมโคมสิบมาแตกเป็นโคมหนึ่งสิบดวง
ถ้าทิ้งโลกโคมไฟ ต้องคิดอุปมาใหม่ทั้งหมด ไม่ใช่แค่เปลี่ยนสี

อุปมาที่น่าจะเข้ากับธีมเพจมากกว่า: **เหรียญสิบกับเหรียญบาท** — เด็กจับต้องได้จริง
แลกเหรียญสิบหนึ่งเหรียญเป็นเหรียญบาทสิบเหรียญ คือการกระจายพอดี และตรงกับ
ของที่ skill `lesson-storytelling` บอกว่าเด็กไทยคุ้นมือ (ขนม ลูกอม เงินเหรียญ นิ้วมือ)

อัดบทนี้ตอนนี้จะเสียเปล่า
