# คลิปสอน #3 — เศษส่วน (ธีมเดียวกับหน้าเพจ)

ทำไมครึ่งหนึ่งมากกว่าหนึ่งในสาม ทั้งที่ 3 มากกว่า 2 · 34.2 วินาที · 1080×1920

**ธีมตามหน้าเพจจริง** ฟ้าสดใส เมฆขาว ตัวหนังสือหนาขอบขาว ชมพูบานเย็น ปุ่มกลมใหญ่ ดูดเดิลดาว
**ไม่ใช้โลกโคมไฟกลางคืนและไม่ใช้ตัวละครแฟนตาซี** — เจ้าของบอกว่าอยากได้แบบคนทั่วไป
คนในคลิปจึงเป็นรูปคนเรียบ ๆ หัวกลมไหล่มน ไม่มีหน้าตา ใช้บอกว่า "มีกี่คนมาแบ่ง" เท่านั้น

## วิธีสอนที่ใช้

ตาม skill `lesson-storytelling` — โครง 6 จังหวะ และจังหวะที่สำคัญที่สุดคือ **ชี้จุดที่คิดพลาด**
เด็กที่ตอบ "หนึ่งในสาม" มีเหตุผลของเขา (3 มากกว่า 2) ถ้าไม่บอกว่าเขาคิดพลาดตรงไหน เขาจะผิดซ้ำที่เดิม

| จังหวะ | เนื้อหา |
|---|---|
| สะดุด | ครึ่งหนึ่ง กับ หนึ่งในสาม อันไหนมากกว่า |
| เจอปัญหา | เด็กส่วนใหญ่ตอบหนึ่งในสาม เพราะ 3 มากกว่า 2 |
| ลองผิด | ขีดฆ่า "3 มากกว่า 2" — เทียบเลขล่างตรง ๆ ไม่ได้ |
| จุดพลิก | เลขล่างคือ **จำนวนคนที่มาแบ่ง** · เค้กก้อนเท่ากัน แบ่ง 2 คน กับ 3 คน |
| ทำซ้ำ | หนึ่งในสี่ กับ หนึ่งในหก |
| ส่งไม้ต่อ | ประเมินพื้นฐานฟรี + เบอร์โทร |

## สิ่งที่ตัวตรวจจับได้ระหว่างทาง

| ข้อ | ที่แก้ |
|---|---|
| เลขเศษส่วนสีขาวบนฟ้าอ่อน 1.45:1 (ต้องการ 3:1) | เปลี่ยนเป็นสีเข้ม — สีขาวใช้ได้เฉพาะบนพื้นเข้มหรือมีขอบหนา |
| ปุ่มเบอร์โทรขาวบนเหลืองส้ม 1.92:1 | เปลี่ยนปุ่มเป็นชมพูบานเย็น (ตรงกับปุ่ม CTA ในโพสต์ของเพจอยู่แล้ว) |
| บรรทัดเฉลยสีเขียว 2.73:1 | ใช้เขียวเข้มขึ้น |
| หัวลูกศรทับเลขล่างของเศษส่วน | เลื่อนลูกศรลงใต้ตัวเศษส่วน (สูง ~284px) |
| ป้ายใต้เค้กชนกับแถบเทียบขนาด | เก็บป้ายก่อนแถบขึ้น |
| ชั้นขอบขาวของตัวหนังสือถูกนับเป็นข้อความซ้อนกัน | ใส่ `data-layout-ignore` ที่ชั้นขอบ เพราะมันเป็นพื้นผิว ไม่ใช่ข้อความที่ต้องอ่าน |

## บั๊กที่ตัวตรวจจับไม่ได้ ต้องดูภาพเอง

**อย่า `scale` `<path>` ใน SVG ด้วย GSAP** — มันคิดจุดหมุนจากกรอบของ path เอง พอจบที่ scale 1
ยังเหลือการเลื่อนค้าง ชิ้นเค้กที่ระบายสีเลยหลุดออกนอกวง ใช้ความหนาเส้นขอบเด้งแทน
ได้ความรู้สึกป๊อปเหมือนกันและไม่ขยับ
