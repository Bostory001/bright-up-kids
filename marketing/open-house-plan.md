# แผนกิจกรรมทดลองเรียนฟรี / วันเปิดบ้าน (M5)

เป้าหมาย: เปลี่ยน "ผู้สนใจ" เป็น "สมัครเรียน" — ตัวเลขทุกขั้นดูได้ที่หลังบ้าน > ผู้สนใจ (กรวย: ทั้งหมด → นัด → มาจริง → สมัคร)

## ก่อนวันงาน

- [ ] กำหนดรอบ: รอบละ `[45–60]` นาที รับ `[4–6]` คนต่อรอบ แยกตามช่วงชั้น (ป.1–2 / ป.3–4 / ป.5–6)
- [ ] ทุกรายชื่อจาก `/trial` โทรกลับภายใน 1 วัน → ใส่วันนัดและเปลี่ยนสถานะเป็น "นัดทดลองเรียนแล้ว"
- [ ] โทร/LINE ยืนยันอีกครั้ง 1 วันก่อนงาน
- [ ] เตรียม tablet `[จำนวน]` เครื่อง ชาร์จเต็ม ต่อ Wi-Fi แล้ว
- [ ] สร้างบัญชีนักเรียนทดลอง (หลังบ้าน > นักเรียน > เพิ่มนักเรียน) สำหรับใช้ในงาน และเผยแพร่ชุดโจทย์ง่าย ๆ ชั้นละ 1–2 ชุด
- [ ] ของรางวัลเล็ก ๆ สำหรับเด็กทุกคนที่มา + เอกสารสมัคร + ใบยินยอมถ่ายภาพ

## ลำดับในแต่ละรอบ

| เวลา | กิจกรรม | ใครทำ |
|---|---|---|
| 0–5 นาที | ต้อนรับ ลงชื่อ ขอใบยินยอมถ่ายภาพ | ผู้ช่วย |
| 5–25 | ครูสอนเนื้อหาสั้น 1 เรื่อง แบบที่สอนจริง | ครู |
| 25–40 | เด็กทำแบบฝึกหัดบน tablet เก็บพลัง ปลดล็อกตัวละคร | ครู + ผู้ช่วย |
| 25–40 (พร้อมกัน) | เจ้าของคุยกับผู้ปกครอง: โชว์หน้าผู้ปกครองและตัวอย่างข้อความ LINE ตอบคำถาม | เจ้าของ |
| 40–50 | ครูบอกผู้ปกครองรายคน: ลูกทำได้ดีเรื่องไหน ควรเสริมเรื่องไหน (จากผลที่เพิ่งทำ) | ครู |
| 50–60 | แจกของรางวัล แจ้งโปรและวันหมดเขต รับสมัครหน้างาน | เจ้าของ |

## หลังวันงาน

- [ ] เปลี่ยนสถานะทุกรายเป็น "มาทดลองเรียนแล้ว" หรือจดว่าไม่มา
- [ ] ผู้ที่สมัคร: ให้กรอก `/enroll` (มีการยินยอม PDPA) แล้วอนุมัติในหน้าใบสมัคร → เปลี่ยนสถานะผู้สนใจเป็น "สมัครเรียนแล้ว"
- [ ] ผู้ที่ยังไม่ตัดสินใจ: โทรตามภายใน 3 วัน พร้อมบอกจุดที่ลูกควรเสริม
- [ ] ผู้ที่ไม่สนใจ: เปลี่ยนเป็น "ไม่สนใจ" · ถ้าขอให้ลบข้อมูลกด "ลบข้อมูล"
- [ ] ลบบัญชีนักเรียนทดลอง หรือปิดสถานะ "ยังเรียนอยู่"

## อ่านตัวเลขอย่างไร

| ถ้า... | แปลว่า | ลองแก้ |
|---|---|---|
| ผู้สนใจน้อย | คนยังไม่เห็น | เพิ่มใบปลิวหน้าโรงเรียน/หมู่บ้าน ดูว่าช่องทางไหนได้รายชื่อมากสุดแล้วทุ่มช่องทางนั้น |
| สนใจเยอะ แต่นัดน้อย | โทรกลับช้า หรือรอบไม่ตรงเวลาว่าง | โทรภายในวันเดียว เพิ่มรอบเย็นวันธรรมดา |
| นัดเยอะ แต่มาน้อย | ลืม/ไม่เห็นความสำคัญ | ยืนยัน 1 วันก่อน ส่งแผนที่ |
| มาเยอะ แต่สมัครน้อย | ราคา หรือยังไม่เห็นความต่าง | ถามเหตุผลตรง ๆ จดไว้ในช่องบันทึก ปรับโปร/การนำเสนอ |
