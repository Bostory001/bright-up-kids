# สเปกเนื้อหาบทเรียน (Lesson Content) — ใช้เขียนและตรวจก่อนนำเข้าระบบ

บทเรียน 1 บท = **การ์ดสอน 3-6 ใบ → โจทย์ 8-12 ข้อ** (นักเรียนอ่านการ์ดก่อน แล้วทำโจทย์ หรือเลือก "ลองแค่ 3 ข้อ" ให้ระบบสุ่ม 3 ข้อจากชุดนี้ → ได้ดาว 1-3)
นำเข้าเป็น **ร่าง (published=false)** เสมอ → ครูตรวจในหน้า `/admin/exercises` แล้วค่อยเผยแพร่

## ไฟล์
`web/content/<วิชา>/<ชั้น>.json` เช่น `web/content/math/p1.json` (ป.1=p1 … ป.6=p6, ม.1=m1)

```json
{
  "grade": 1,
  "subject": "math",
  "lessons": [
    {
      "term": 1,
      "unit": "จำนวนนับ 1 ถึง 10",
      "order": 1,
      "title": "นับและอ่านจำนวน 1 ถึง 10",
      "topic": "จำนวนนับ",
      "teach": [
        { "title": "มานับกัน", "text": "ข้อความสอนสั้น ๆ ...", "example": "🍎🍎🍎 = 3" }
      ],
      "questions": [
        { "prompt": "🍎🍎🍎🍎 มีกี่ผล?", "choices": ["3", "4", "5", "6"], "answerIndex": 1, "explain": "นับทีละผล 1-2-3-4 ได้ 4 ผล" }
      ]
    }
  ]
}
```

## กฎฟิลด์ (ตัวตรวจ `npm run validate:content` เช็กให้)
- `subject` = math | thai | english | science | chinese · `grade` 1-9 (ม.1=7)
- `term` 1 หรือ 2 · `unit` = ชื่อหน่วย (≤80) บทหลายบทอยู่หน่วยเดียวกันได้ · `order` = ลำดับตลอดทั้งชั้น เริ่ม 1 ต่อเนื่อง ไม่ซ้ำ (ลำดับที่เด็กเรียน)
- `title` ≤100 ไม่ซ้ำในไฟล์ · `topic` ≤60 (ใช้สรุปจุดอ่อนรายคน เช่น "การบวก")
- `teach`: 3-6 ใบ · `title` ≤60 · `text` ≤400 · `example` ≤200 (ไม่บังคับ)
- `questions`: 8-12 ข้อ · `prompt` ≤500 · `choices` **4 ตัวพอดี ไม่ซ้ำ** ≤200 · `answerIndex` 0-3 · `explain` ≤500 (บังคับ)
- คำตอบที่ถูกต้อง **กระจายอย่างน้อย 3 ตำแหน่ง** ในแต่ละบท (อย่ากอง 0 หรือ 1)

## กฎเนื้อหา (เจ้าของยืนยัน + กฎโปรเจกต์)
1. **แต่งเองทั้งหมด** — ใช้เนื้อหาหลักสูตรแกนกลาง (สพฐ./สสวท. ตัวชี้วัด) เป็นขอบเขตว่าชั้นนี้เรียนอะไร แล้วเขียนตัวเลข บริบท โจทย์ใหม่เอง **ห้ามคัดลอก/ดัดแปลงใกล้เคียง** จากหนังสือเรียน แบบฝึกหัดของ HQ เว็บติวเตอร์ หรือเว็บคู่แข่ง
2. **ถูกต้อง 100%** — ตรวจคำตอบเองซ้ำทุกข้อ มีคำตอบถูกเพียงข้อเดียว ตัวเลือกหลอกต้องเป็นความผิดพลาดที่เด็กพบบ่อย (เช่น ลืมทด, บวกแทนลบ)
3. **ภาษาเด็ก** — ประโยคสั้น เหมาะระดับชั้น (ป.1-2 ใช้ emoji ช่วยนับ/เห็นภาพได้) บริบทไทย (บาท, มะม่วง, ขนมครก, โรงเรียน) ไม่ใช้ข้อมูลเด็กจริง
4. **เฉลยแบบพี่สอนน้อง** — `explain` อธิบายวิธีคิดสั้น ๆ 1-3 ประโยค ไม่ตำหนิ (ห้ามคำว่า "ผิด" ให้ใช้ "ลองคิดแบบนี้นะ")
5. **ความยาก** — ในแต่ละบท: ง่าย 3 · กลาง 4 · ท้าทาย 1-3 (รวมโจทย์ปัญหาอย่างน้อย 2 ข้อ ถ้าหัวข้อมี)
6. **ไม่มีรูปภาพ** — ข้อความล้วน (เรขาคณิตให้บรรยายเป็นคำ/ใช้ emoji รูปร่าง ⬜ ⭕ 🔺)
7. การ์ดสอนต้องสอนจริง: นิยาม → ตัวอย่างทำให้ดู → เคล็ดลับ/ข้อควรระวัง (ไม่ใช่แค่ทวนโจทย์)
9. **โจทย์ทุกข้อต้องอยู่ได้ด้วยตัวเอง** — โหมด "ลองแค่ 3 ข้อ" สุ่มข้อมาเดี่ยวๆ ห้ามเขียนว่า "จากข้อมูลเดิม/ข้อก่อนหน้า/จากตารางข้างบน" ต้องใส่ข้อมูลที่ใช้ตอบไว้ในโจทย์เอง
10. ตัวเลขในโจทย์ไม่ซ้ำกับตัวอย่างในการ์ดสอน (กันเด็กลอกจากการ์ด) และไม่ใช้เนื้อหาเกินระดับชั้น (เช่น จำนวนลบใน ป.4)
8. เริ่มที่หัวข้อแรกของหลักสูตรชั้นนั้นได้เลย ไม่ต้องมีบทแนะนำ

## ขนาดที่ต้องการต่อชั้น (คณิต)
12-18 บทต่อชั้น ครอบคลุมสาระ จำนวนและพีชคณิต · การวัดและเรขาคณิต · สถิติและความน่าจะเป็น (ตามที่ชั้นนั้นมี) แบ่งเทอม 1 / เทอม 2 ให้สมดุล

## ขั้นตอน
```bash
cd web
npm run validate:content          # ตรวจรูปแบบ
npm run import:content            # (dry-run) ดูว่าจะสร้างอะไร
npm run import:content -- --apply # นำเข้าเป็นร่าง ผ่าน admin API (ADMIN_BASE_URL ใน .env.local)
```
นำเข้าซ้ำได้: ชุดที่ชื่อ+ชั้น+วิชาตรงกัน จะถูกอัปเดตเนื้อหา (ไม่สร้างซ้ำ และ **ไม่เปลี่ยนสถานะเผยแพร่**)
