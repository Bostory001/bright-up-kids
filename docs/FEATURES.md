## B. ฟีเจอร์เฉพาะสถาบันเรียนพิเศษ

**หลังบ้าน**
- สมัครเรียนออนไลน์ + ยินยอม PDPA ของผู้ปกครอง
- คอร์ส / ตารางเรียน / เช็กชื่อบน tablet
- ใบแจ้งค่าเรียน, แนบสลิป, ติดตามค้างชำระ
- แจ้งเตือน LINE: ถึงสถาบันแล้ว / ขาดเรียน / ค่าเรียนครบกำหนด / สรุปผลรายสัปดาห์
- เรียนชดเชย, ทดลองเรียนฟรี (ต่อกับการตลาด — เก็บ lead)

**แบบฝึกหัดออนไลน์ + เกม**
- คลังโจทย์แยกวิชา/ชั้น, ครูมอบหมายเป็นการบ้านรายห้องได้
- วัดพลัง: XP → เลเวล → ฉายา
- Achievement (ทำครบ, เต็มร้อย, ขยันติดกัน N วัน)
- Avatar + สกินแต่งตัว ปลดล็อกจากเลเวล/achievement
- เหรียญ → แลกของรางวัลจริงที่สถาบัน (ครูกดอนุมัติส่งมอบ)
- กระดานอันดับรายห้อง (ทางเลือก — ต้องระวังเด็กที่ตามไม่ทันหมดกำลังใจ)

**ผู้ปกครอง**
- หน้าเดียวจบ: วันนี้ลูกมาเรียนไหม, ทำแบบฝึกหัดกี่ชุด, จุดที่ควรเสริม, ยอดค้างชำระ
