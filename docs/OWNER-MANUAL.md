# คู่มือเจ้าของ — Bright Up Kids สาขาวัดหลวงพ่อโต บางพลี

คู่มือนี้เรียงตาม **งานที่เจ้าของต้องทำจริง** (ไม่ใช่ตามเมนู) · รายละเอียดทีละหน้าดูที่ `/admin/help` ในระบบ

> สิทธิ์ของเจ้าของ = เห็น/แก้ได้ทุกอย่าง · หน้าที่เฉพาะเจ้าของ: **งบประมาณ, ค่าจ้างครู, ผู้ใช้**, การแก้คอร์ส/ตั้งค่า, รายงานยอดรับ + royalty

---

## 0. เข้าระบบ

| เรื่อง | วิธี |
|---|---|
| ครั้งแรกสุด | เปิด `/setup` สร้างบัญชีเจ้าของ (ทำได้ครั้งเดียว) |
| เข้าประจำ | `/login` → อีเมล/รหัสผ่าน → เลข 6 หลักจากแอป Authenticator (2FA บังคับ) |
| ตั้ง 2FA | เมนู **ความปลอดภัย** → สแกน QR ด้วย Google/Microsoft Authenticator → กรอกเลข 6 หลัก |
| มือถือหาย | ทำเองไม่ได้ (เจ้าของ) → ต้องแก้ผ่านเครื่องที่ดูแลระบบ · **สำรอง QR/secret ตอนตั้ง 2FA ไว้** |
| ล็อกอินผิด 5 ครั้ง | ถูกล็อก 10 นาที รอแล้วลองใหม่ |

ลิงก์ที่ใช้แจกคนอื่น: `/enroll` (ใบสมัครเรียน) · `/trial` (ขอทดลองเรียนฟรี) · `/parent` (ผู้ปกครอง) · `/play` (นักเรียน)

## 1. ทุกเช้า (5 นาที)

1. **ภาพรวม** — ดูการ์ด: ใบสมัครรออนุมัติ · สลิปรอตรวจ · ยอดค้างชำระ · งบของรางวัล
2. **ใบสมัคร** — มีรายการ → กด *อนุมัติ* → ระบบสร้างนักเรียน + บัญชีผู้ปกครอง + ลงคอร์ส + ออกใบแจ้งค่าเรียน
   - ⚠️ **รหัสนักเรียน + PIN + รหัสผ่านชั่วคราวผู้ปกครองแสดงครั้งเดียว** จดแล้วส่งให้ผู้ปกครองทันที
3. **ผู้สนใจ** — โทรกลับลูกค้าที่ขอทดลองเรียนภายใน **1 วัน** แล้วเปลี่ยนสถานะ (ติดต่อแล้ว → นัดทดลอง → มาทดลองแล้ว → สมัครแล้ว)
4. **ค่าเรียน** — ใบสถานะ *รอตรวจสลิป* → *ดูสลิป* → ตรงยอดจึงกด *ยืนยันรับเงิน*
5. **คลาสออนไลน์** — ถ้ามีแถบแดง = คาบวันนี้ยังไม่มีลิงก์ Meet ให้ใส่ก่อน (ระบบส่งลิงก์ให้ผู้ปกครองก่อนคาบ 30 นาที)

## 2. วันที่มีคาบสอน

- **เช็กชื่อ** (ครูทำบน tablet): เลือกคอร์ส+วัน → แตะ มา/สาย/ขาด/ลา → *บันทึก* → ผู้ปกครองได้ LINE เฉพาะคนที่สถานะเปลี่ยน
  - ⚠️ **ครูต้องเช็กชื่อทุกคาบ** — ชั่วโมงสอนที่คิดค่าจ้างมาจากการเช็กชื่อเท่านั้น
- **เรียนชดเชย**: คาบที่ขาด/ลาขึ้นอัตโนมัติ → เลือกวัน → *นัด + แจ้งผู้ปกครอง* → เด็กมาแล้วกด *มาเรียนแล้ว*
- **ใบตารางสอนครู**: เลือกครู → *พิมพ์/ส่ง PDF* ทาง LINE ก่อนวันสอน (มีรายชื่อเด็ก เบอร์ผู้ปกครอง จำนวนขาด/ลา)

## 3. ทุกสัปดาห์

| งาน | หน้า | ทำอะไร |
|---|---|---|
| ส่งสรุปผลการฝึกให้ผู้ปกครอง | แจ้งเตือน LINE | กด *ส่งสรุปรายสัปดาห์* · ข้อความ "ค้างส่ง" = ผู้ปกครองยังไม่ผูก LINE |
| สั่งการบ้าน | การบ้าน | เลือกคอร์ส + ชุดโจทย์ที่เผยแพร่แล้ว + กำหนดส่ง · ดูแถบเขียว/รายชื่อคนยังไม่ทำ |
| เตือนค้างชำระ | ค่าเรียน | *เตือนค้างชำระ* ส่งถึงผู้ปกครองที่ใกล้/เลยกำหนด |
| ส่งของรางวัล | ของรางวัล | รายการ *รอส่งมอบ* → ให้ของจริง → กด *ส่งมอบ* (เกินงบ 3,000/เดือนระบบไม่ให้ส่ง → รอเดือนหน้าหรือ *ปฏิเสธ* คืนเหรียญ) |
| เช็กตารางชน | ตารางสอน | กล่องแดงด้านบน = ครู/ห้องชนกัน ต้องแก้ที่หน้า *คอร์ส* |
| ของใกล้หมด | คลังของใช้ | ดูคอลัมน์ "จะหมดใน" แล้ววางแผนซื้อ |

## 4. สิ้นเดือน (ปิดบัญชี)

ทำตามลำดับ — ตัวเลขกำไรขึ้นกับข้อก่อนหน้า

1. **ค่าเรียน** — ยืนยันสลิปที่ค้างให้หมด
2. **รายจ่าย** — บันทึกให้ครบ (ค่าเช่า, ของเบ็ดเตล็ด) · ติ๊ก *รายจ่ายประจำ* กับค่าเช่า/เงินเดือน · แนบรูปใบเสร็จ
   - ซื้อของเข้าคลังให้เลือกช่อง *ตัดเข้าคลัง* จำนวนจะเข้าคลังเอง
3. **ค่าจ้างครู** — เช็กชั่วโมงรายคน (กดชื่อดูรายคาบ) → แก้ยอดถ้ามีหักลา/โบนัส → *บันทึกจ่าย* → ไปเป็นรายจ่ายหมวดค่าจ้างครูอัตโนมัติ
4. **งบประมาณ** — ดูแถบ เขียว/เหลือง/แดง (ใช้ <80% / ใกล้เต็ม / เกินงบ) และ % ถึงเป้ากำไร
5. **รายงาน** → *กำไร–ขาดทุนรายเดือน* · สูตร: **รายรับ − รายจ่าย − royalty = กำไร**
   - royalty = **23%** ของค่าเรียน (ค่าตั้งต้น — **ต้องตรวจกับสัญญา HQ**; แก้ได้ที่ *ตั้งค่า*)
6. **ปฏิทินการเรียน** — ดูคอร์สที่ใกล้จบ (เหลือกี่สัปดาห์) เพื่อทักผู้ปกครองต่อคอร์สล่วงหน้า

## 5. เปิดคอร์ส / รับนักเรียนใหม่

1. **คอร์ส** → เพิ่มคอร์ส: ชั้นที่รับ, วัน-เวลา, ค่าเรียนต่อเทอม, ครู, ห้อง, **วันเริ่ม + จำนวนสัปดาห์** (ไม่ใส่ปฏิทินไม่ขึ้น), ติ๊ก *เรียนออนไลน์* ถ้าเป็นออนไลน์
2. **ตารางสอน** → ตรวจว่าไม่มีกล่องแดง
3. รับสมัคร: ส่งลิงก์ `/enroll` หรือ QR · **ต้องมีการยินยอม PDPA ของผู้ปกครอง** (ฟอร์มมีช่องให้แล้ว) · หน้าร้านกรอกเอง → ให้ผู้ปกครองเซ็นกระดาษก่อน
4. **นักเรียน** → *บัตร* พิมพ์ QR ให้เด็ก · ลืม PIN → *PIN ใหม่*
5. ก่อน/หลังจบคอร์ส → **คะแนนก่อน-หลัง** บันทึกคะแนน (ได้ตัวเลข "พัฒนาการ +กี่จุด" ไว้คุยกับผู้ปกครองและทำการตลาด)

## 6. จัดการครู (เฉพาะเจ้าของ)

- **ผู้ใช้** → เพิ่มครู → ส่งรหัสผ่านชั่วคราวให้ → ครูตั้ง 2FA เองตอนเข้าครั้งแรก
- ใส่ **ค่าสอน/ชม.** ของครูแต่ละคน (ไม่งั้นหน้าค่าจ้างคิดไม่ได้)
- ครูทำมือถือหาย → *รีเซ็ต* (ล้าง 2FA + ออกรหัสผ่านใหม่)
- ครูลาออก → ปิดบัญชี (ไม่ลบ เพื่อเก็บประวัติเช็กชื่อ/ค่าจ้าง)
- กำลังหาครู: ดู [HIRING.md](HIRING.md)

## 7. ผู้ปกครองและนักเรียนเห็นอะไร

| | เข้าระบบ | เห็น |
|---|---|---|
| **ผู้ปกครอง** `/parent` | เบอร์โทร + รหัสผ่าน | การเข้าเรียน, ผลแบบฝึกหัด, ตารางของลูก, คะแนนก่อน-หลัง, ใบแจ้งค่าเรียน (แนบสลิปได้) · กด *ผูก LINE* แล้วส่งรหัส 6 หลักในไลน์สถาบัน |
| **นักเรียน** `/play` | สแกน QR หรือรหัสนักเรียน + PIN 4 หลัก | แบบฝึกหัด, คลิปสอน, เหรียญ, ของรางวัล |

กติกาเกมที่ตั้งไว้: ลิมิตวันละ 3 ชม. หรือครบจำนวนโจทย์ (เกินแล้วเล่นต่อได้แต่ไม่นับคะแนน) · งบของรางวัล 3,000 บาท/เดือน · **เด็กไม่ได้คุยกับ AI** (AI ใช้ฝั่งครู/เจ้าของเท่านั้น)

## 8. เนื้อหา (แบบฝึกหัด / คลิปสอน)

- **แบบฝึกหัด** → *สร้างชุดใหม่* หรือวางจาก Excel → ตรวจเองให้จบ → ติ๊ก *เผยแพร่* (เด็กชั้นนั้นเห็นทันที)
  - ⚠️ **ห้ามคัดลอกโจทย์จากเอกสาร/หนังสือ HQ** — แต่งเองเท่านั้น
- **คลิปสอน** → นำเข้า (`npm run import:lessons` ที่โฟลเดอร์ `web`) → ดูคลิปเองให้จบ → *เผยแพร่*
- **ผู้ช่วย AI** → ถามเป็นภาษาไทย เช่น "ใครค้างค่าเรียน", "น้องคนไหนอ่อนเรื่องอะไร" · AI เห็นแค่รหัส+ชื่อเล่น+สถิติ คำตอบเป็นข้อเสนอ ตัดสินใจเอง

## 9. ตั้งค่า (เจ้าของ)

หน้า **ตั้งค่า**: จำนวนโจทย์/เวลาต่อวัน · งบของรางวัล · อัตรา royalty · เป้ากำไรต่อเดือน · ตัวช่วยตั้งราคาของรางวัล (ใส่จำนวนนักเรียน → รู้ว่าควรตั้งกี่เหรียญไม่ให้เกินงบ)

## 10. ข้อควรระวัง (อ่านก่อนทำอะไรเสี่ยง)

- **PDPA**: เก็บข้อมูลเด็กเท่าที่จำเป็น · ต้องมีความยินยอมผู้ปกครองก่อนสร้างนักเรียน · อย่าใส่ข้อมูลเด็กจริงลง repo/แชต · ผู้ปกครองขอลบข้อมูล → ใช้ปุ่ม *ลบข้อมูล* ที่หน้าผู้สนใจ / ติดต่อผู้ดูแลระบบ · ดูรายการข้อมูลที่เก็บที่ *Data Dictionary*
- **แบรนด์/ลิขสิทธิ์**: ชื่อ-โลโก้ Bright Up Kids เป็นของ HQ — สื่อการตลาดที่ใช้แบรนด์ต้องได้รับอนุญาตก่อน · คลิป/สื่อที่ใช้เนื้อหา HQ เคลียร์ก่อนเปิดให้เด็กดู
- **ยอดเงิน**: ระบบคิดฝั่ง server ที่เดียว อย่าแก้ตัวเลขนอกระบบ · แก้ข้อมูลจริง (นักเรียน/คอร์ส/เงิน) ผ่าน `web/scripts/admin-api.mjs` ตาม [DATA_EDITING.md](DATA_EDITING.md) ไม่แก้ Firestore ตรง
- **ยังไม่ได้ต่อของจริง** (ณ ตอนนี้): LINE, Firestore/Vercel, AI ดูขั้นตอนใน [GO_LIVE.md](GO_LIVE.md) — จนกว่าจะต่อ ข้อความ LINE จะขึ้น "ค้างส่ง"
