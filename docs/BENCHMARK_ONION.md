## 2. โครงที่เอามาใช้ได้เลย

### 2.1 คลิปสอน = **5-8 นาที ต่อ 1 คอนเซปต์** (ไม่ใช่คลิปยาว ไม่ใช่คลิปสั้น 60 วิ)

เขาบอกเองว่าเฉลี่ย 5-8 นาที และเนื้อหาเน้น **"ที่มาและพัฒนาการของแนวคิดนามธรรม"** ไม่ใช่สอนวิธีทำอย่างเดียว

**ของเราต้องแยก 2 แบบให้ชัด** (ตอนนี้ปนกันอยู่)

| แบบ | ยาว | ใช้ที่ไหน | เป้าหมาย |
|---|---|---|---|
| **คลิปสอน** | 5-8 นาที | ในแอป แปะกับชุดโจทย์ | เข้าใจคอนเซปต์ |
| **คลิปโซเชียล** | ≤60 วิ 6 จังหวะ | FB/TikTok | ให้คนรู้จัก |

→ เพิ่มเป็น **F0** ใน BACKLOG

### 2.2 **วิดีโอกับชุดฝึกต้องมาคู่กันเสมอ**

เขาเรียกว่า "integrate learning and practice" — ดูจบแล้วมีโจทย์ต่อทันที
**ของเรามีครบทั้งสองฝั่งแล้ว แต่ยังไม่ได้ผูกกัน** → ผูกด้วย `topic` ที่มีอยู่ใน `Exercise` อยู่แล้ว ไม่ต้องแก้ schema

### 2.3 **คลังข้อสอบแบ่งตามระดับความยาก ไม่ใช่กองรวม**

เขาแบ่งข้อตาม "gradient" และ "core competency"
**ของเรายังไม่มี** — `Exercise` มี `subject` `grade` `topic` แต่ **ไม่มีฟิลด์ความยาก**
ทำให้ทำสองอย่างนี้ไม่ได้: คัดโจทย์ง่ายให้เด็กที่เพิ่งผิด · เรียงชุดจากง่ายไปยากอัตโนมัติ
→ เพิ่มเป็น **D7** ใน BACKLOG

### 2.4 **ครูสั่งการบ้านได้ (assignment builder)**

เขามีให้ครูประกอบชุดแล้วสั่งเด็ก — ตรงกับโมเดล 17zuoye ที่เจ้าของสนใจตั้งแต่แรก
**ของเรายังไม่มี** แต่ **อย่าเพิ่งทำ** จนกว่า A7 จะบอกว่าครูสาขาอยากได้จริง (ไม่งั้นสร้างของที่ไม่มีคนใช้)

### 2.5 **อิงหลักสูตรชาติ และบอกให้ชัดว่าตรงกับหนังสือเล่มไหน**

เขาย้ำ "aligned with national curriculum standards" + "adapt to various versions of textbooks"
**สำหรับเรานี่คือเรื่องความน่าเชื่อถือกับผู้ปกครอง** — ทุกชุดโจทย์ควรระบุว่าอิงหลักสูตรแกนกลางหัวข้อไหน
⚠️ ระบุว่า "อิงหลักสูตร" ได้ แต่ **ห้ามอ้างว่าตรงกับหนังสือของ HQ หรือลอกเนื้อหามา** (ข้อจำกัดแฟรนไชส์)

## 3. โครงที่ **ยังไม่ต้องสนใจ**

| ของเขา | ทำไมยังไม่ใช่ตอนนี้ |
|---|---|
| Knowledge graph + dynamic learning pathway | ต้องใช้ข้อมูลพฤติกรรมระดับพันล้านครั้ง เรามี 0 — เวอร์ชันที่ทำได้จริงคือ "หัวข้อที่ผิดบ่อย → เสนอชุดถัดไป" ซึ่งรายงาน R10 ทำได้แล้ว |
| แท็บเล็ตเรียนของตัวเอง | ขัดกับ EPIC E โดยตรง — กลุ่มเป้าหมายเรามีแค่มือถือเครื่องเดียว |
| Integrated publishing (ขายหนังสือ) | ชนลิขสิทธิ์ HQ เต็ม ๆ |
| ระบบให้โรงเรียนทั้งเขตใช้ | เรายังไม่เปิดสาขาด้วยซ้ำ |

## 4. เรื่องที่ต้องระวัง

- สโลแกนเขาคือ **"Digital learning for all"** — ซึ่งเกือบตรงกับไอเดียข้อ 1 ที่เจ้าของชอบ
  **ห้ามใช้ประโยคนี้เป็นสโลแกนของเรา** คิดคำของตัวเองที่สื่อเรื่องเดียวกัน
- ตัวเลขทั้งหมดในหน้านี้เป็น **ตัวเลขที่เขาเผยแพร่เอง** ไม่มีใครตรวจสอบ — ใช้ดูทิศทางได้ อย่าเอาไปอ้างในสื่อการตลาดของเรา
- เขาโตด้วยเงินทุน 84.6 ล้าน USD และโรงเรียนรัฐจีน **เส้นทางนี้เราเดินตามไม่ได้** สิ่งที่เราลอกได้คือรูปแบบสื่อ ไม่ใช่กลยุทธ์การเติบโต
