> **จุดที่ยังไม่ได้ตัดสินใจ (อย่าให้ข้อมูลแทนเจ้าของ):** ราคา · วันเวลาเปิดคอร์ส · จำนวนเด็กต่อห้อง · มีทดลองเรียนไหม · เปิดสอนออนไลน์จริงหรือยัง → ถามเจ้าของก่อนตอบ

## 1. อธิบายใน 30 วินาที
"คอร์ส Coding ของเราสอนให้เด็กคิดเป็นขั้นตอน แก้ปัญหาเป็น ผ่านการสร้างเกมและผลงานของตัวเอง เริ่มจากเกมกับกิจกรรม (ป.1–2) ต่อด้วยโปรแกรม Scratch ที่ลากบล็อก (ป.3–6) แล้วค่อยเขียนโค้ด Python จริง (ม.1–3) ทุกคอร์สสั้น 6–8 ครั้ง จบแล้วเด็กได้ผลงานกลับบ้านค่ะ"

**จุดขายที่พูดได้จริง** (ทุกข้อมีในหลักสูตรแล้ว)
- เรียนผ่านการลงมือสร้าง ไม่ใช่นั่งฟัง
- ทุกคอร์สมีผลงานปลายทางที่เด็กโชว์พ่อแม่ได้
- ซอฟต์แวร์ที่ใช้ฟรี (ไม่ต้องซื้อโปรแกรมเพิ่ม)
- คอร์สย่อย เลือกเรียนทีละคอร์สได้ ไม่ต้องจ่ายยาว
- ครูตรวจงานทีละคนระหว่างเรียน

**ห้ามพูด** (ยังไม่มีหลักฐาน)
- ❌ "เด็กทุกคนจะเก่ง/ได้งานในอนาคต/สอบเข้าโรงเรียนดังได้"
- ❌ "ตรงตามหลักสูตร สสวท. ทั้งหมด" (ยังไม่ได้เทียบตัวชี้วัดทีละข้อ)
- ❌ "ผ่านการทดลองสอนมาแล้ว" (ยังไม่เคยลองสอนกับเด็กจริง)
- ❌ ราคา/ส่วนลด/วันเปิดเรียน (ยังไม่ได้ตั้ง)
- ❌ อ้างชื่อหรือโลโก้ Scratch ในโฆษณา

- คาบละ **60 นาที** (ออนไลน์อาจสั้นลง 40–45 นาทีสำหรับเด็กเล็ก)
- ทุกคอร์สครูให้คะแนนทักษะเป็น 3 ระดับ (ต้องช่วย / ทำได้เมื่อแนะนำ / ทำเองได้) ไม่มีสอบเขียน
- เด็กไม่ต้องเรียนครบทุกคอร์ส เลือกเข้าตามอายุและพื้นฐาน

### เส้นทางเรียนต่อ
```
A1 → A2 ─┐
         ├→ B1 → B2
         │    └→ B3 → B4 ─┐
                           ├→ C1 → C2 ─┐
                           │    └→ C3 ─┴→ C4
```
ตัวอย่างการแนะนำ: "ลูกอยู่ ป.4 ไม่เคยเขียนโค้ด → เริ่ม B1 แล้วต่อ B3 ค่ะ"

## 3. แนะนำคอร์สให้ผู้ปกครอง (ตัดสินใจเร็ว)

| ลูกอยู่ชั้น | เคยเขียนโค้ด/Scratch? | แนะนำเริ่ม |
|---|---|---|
| ป.1–2 | ไม่เคย | **A1** แล้วต่อ A2 |
| ป.3 | ไม่เคย | **B1** ⚠️ ตอนนี้ B2–B4 เริ่ม ป.4–5 ยังไม่มีคอร์สต่อให้ ป.3 → ถามเจ้าของก่อนรับสมัครต่อเนื่อง |
| ป.4–6 | ไม่เคย | **B1** (ถ้าอยากทำเกมเลย ถามครูเรื่อง B3) |
| ป.4–6 | เคยเล่น Scratch บ้าง | **B3** (เกมแรก) |
| ป.5–6 | จบ B3 แล้ว | **B4** |
| ม.1–3 | ไม่เคยเขียนโค้ด | **C1** ⚠️ ต้องพิมพ์โค้ดภาษาอังกฤษ สลับคีย์บอร์ดไทย–อังกฤษได้ก่อนยิ่งดี |
| ม.1–3 | เคยเล่น Scratch | **C1** (จะเร็วขึ้น) หรือ **C2** ถ้าชอบวาดรูป |
| ม.2–3 | จบ C1–C3 | **C4** |

**ถ้าไม่แน่ใจ:** ให้ผู้ปกครองระบุชั้นและประสบการณ์ แล้วส่งให้ครู/เจ้าของแนะนำ (ยังไม่มีแบบทดสอบก่อนเข้าเรียน)

## 4. ผู้ปกครองต้องเตรียมอะไร

| คอร์ส | ที่สถาบัน | เรียนออนไลน์ (ถ้าเปิด) |
|---|---|---|
| A1 | ไม่ต้องเตรียม | ผู้ปกครองนั่งด้วย + เปิดเกมในเบราว์เซอร์ + พิมพ์การ์ด/ใบงานตามที่สถาบันส่ง |
| A2 | ไม่ต้องเตรียม | แท็บเล็ต + แอป ScratchJr + ผู้ปกครองนั่งด้วย |
| B1–B4 | ไม่ต้องเตรียม | คอม/โน้ตบุ๊ก + อินเทอร์เน็ตเสถียร + เบราว์เซอร์ล่าสุด + หูฟัง (ไม่บังคับ) |
| C1–C4 | ไม่ต้องเตรียม | คอม/โน้ตบุ๊ก (Windows/Mac) ติดตั้ง Python และ Thonny ก่อนเรียน (**แท็บเล็ตไม่เหมาะ**) |

- ซอฟต์แวร์ทั้งหมดฟรี
- Scratch ใช้ผ่านเว็บ ไม่ต้องติดตั้ง · Python ต้องติดตั้งบนคอม

## 5. คำถามที่ผู้ปกครองถามบ่อย

| คำถาม | คำตอบที่ตอบได้ |
|---|---|
| ลูกไม่เคยเขียนโค้ดเลยจะตามทันไหม | ได้ค่ะ ทุกสายเริ่มจากศูนย์ (A เริ่มจากเกม, B เริ่มที่ B1, C เริ่มที่ C1) แต่ละคาบทบทวนก่อนเริ่ม |
| ต้องมีคอมที่บ้านไหม | เรียนที่สถาบันไม่ต้อง · ถ้าอยากเล่นเกมหุ่นยนต์ต่อที่บ้านใช้เบราว์เซอร์ได้ ไม่ต้องสมัคร |
| ต้องเก่งคณิตไหม | ไม่ต้อง แต่ B2 มีเรื่องมุม (เด็ก ป.4–6 ทำได้ครูอธิบาย) |
| เด็กเล็กเล่นเกมเยอะ จะติดเกมไหม | เกมของเราเป็นเครื่องมือเรียน (สร้างเอง ไม่มีโฆษณา) และมีกิจกรรมบนพื้น/กระดาษคู่กัน |
| เด็กได้ผลงานอะไรกลับบ้าน | ดูตารางข้อ 2 · ไฟล์ผลงานส่งให้ผู้ปกครองได้ |
| เก็บข้อมูลลูกไหม | เกม A1 ไม่เก็บข้อมูลส่วนตัว (คะแนนดาวอยู่ในเครื่องเท่านั้น) · คอร์สอื่นใช้ชื่อเล่น ไม่บังคับสมัครบัญชีออนไลน์ · ขอความยินยอมผู้ปกครองก่อนถ่ายภาพ/เผยแพร่ผลงาน |
| ราคา/ตารางเรียน/จำนวนเด็กต่อห้อง/ทดลองเรียน | **ยังไม่กำหนด — ถามเจ้าของ** |
| เรียนออนไลน์ได้ไหม | หลักสูตรเตรียมไว้แล้ว (B และ C เหมาะมาก, A ต้องมีผู้ปกครองช่วย) แต่ **ต้องถามเจ้าของว่าเปิดสอนออนไลน์จริงหรือยัง** |
| มีใบรับรอง/เกียรติบัตรไหม | มีเกียรติบัตรท้ายคอร์ส (ในแผนสอน) แต่ไม่ใช่ใบรับรองทางการ |
| สอดคล้องกับหลักสูตรโรงเรียนไหม | สอดคล้องแนวคิด เช่น ลำดับ ลูป เงื่อนไข ตัวแปร ของวิชาวิทยาการคำนวณ **แต่ยังไม่ได้เทียบทีละตัวชี้วัด จึงอย่ายืนยันว่า "ตรงหลักสูตร"** |
| ครูผู้สอนเป็นใคร | ยังไม่กำหนด ถามเจ้าของ |

## 6. สิ่งที่ admin ควรรู้เวลาคุยกับผู้ปกครอง
- **เกมหุ่นยนต์หาดาว** เปิดเล่นได้ที่ `/coding/a1/index.html` บนเว็บสถาบัน (หลังเว็บอัปเดตแล้ว) ใช้โชว์ผู้ปกครองได้ เด็กไม่ต้องล็อกอิน
- **ชื่อ Scratch/ScratchJr/Python** ใช้บอกชื่อเครื่องมือได้ แต่ไม่ใช้โลโก้ในโฆษณา
- **โปสเตอร์** ดูไฟล์ prompt ใน `marketing/social/coding-posters/` (ต้องตรวจสะกดไทยก่อนโพสต์)

## 7. ปัญหาที่รู้อยู่แล้ว (แจ้งเจ้าของถ้าเจอผู้ปกครองถาม)
1. เด็ก **ป.3** เรียน B1 จบแล้วยังไม่มีคอร์สต่อ
2. **C (Python)** ต้องพิมพ์โค้ดภาษาอังกฤษ เด็กที่พิมพ์ช้าอาจติด ยังไม่มีบทฝึกพิมพ์
3. คอร์สที่เรียนต่อเนื่องกัน (B3, B4, C4) ถ้าเด็กขาดเรียนจะตามคาบถัดไปยาก ยังไม่มีนโยบายเรียนชดเชย
4. ยังไม่มีแบบทดสอบระดับก่อนเข้าเรียน
5. ยังไม่เคยทดลองสอนกับเด็กจริง
