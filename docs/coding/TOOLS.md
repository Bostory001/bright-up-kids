- เพิ่มเครื่องมือวิดีโอคอล (เลือกหนึ่งเจ้า — ยังไม่ได้ตรวจราคา/ข้อจำกัด) และช่องทางส่งงานของสถาบัน
- เด็กต้องมีคอม/แท็บเล็ตที่บ้าน (A2 ใช้แท็บเล็ต) และติดตั้ง Thonny ก่อนเรียน C
- รายละเอียดทั้งหมด: [ONLINE.md](ONLINE.md)

## 3. บัญชีและข้อมูลเด็ก (PDPA)

- Scratch ต้องสมัครบัญชีเพื่อบันทึกบนคลาวด์ → ใช้ชื่อเล่น/ชื่อสมมติ ไม่ใช้ชื่อจริง ไม่ใช้รูปหน้า
- ถ้าสมัครด้วยอีเมลเด็ก ต้องได้รับความยินยอมจากผู้ปกครอง ทางเลือกที่ปลอดภัยกว่า: ให้เด็กบันทึกไฟล์ลงเครื่องโรงเรียน ไม่ต้องสมัครบัญชี
- ไม่เผยแพร่ผลงานเด็กพร้อมชื่อ/รูปโดยไม่ขออนุญาตผู้ปกครอง (ตามกฎข้อ 4 ของโปรเจกต์)

## 4. ประเด็นลิขสิทธิ์/เชิงพาณิชย์ (ต้องเคลียร์ก่อนขายคอร์ส)

| เรื่อง | สถานะ | สิ่งที่ทำ |
|---|---|---|
| Scratch ใช้ในคอร์สที่เก็บค่าเรียน | **ยังไม่ชัด** — ข้อความในเงื่อนไขมีทั้งส่วนที่ว่า "ใช้ส่วนตัว" และ "เชิงพาณิชย์ได้ตาม CC BY-SA 2.0" | อ่าน scratch.mit.edu/terms_of_use + ส่งอีเมลถาม Scratch Foundation ขอคำตอบเป็นลายลักษณ์อักษร |
| ชื่อ/โลโก้/แมว Scratch ในสื่อการตลาด | จำกัดเฉพาะส่วนตัวและการศึกษา | ไม่ใช้ในโบรชัวร์/โฆษณา |
| เนื้อหา Code.org | ยังไม่ได้ตรวจเงื่อนไขเชิงพาณิชย์ | ใช้เป็นแหล่งฝึกเท่านั้น ใบงานเขียนเองทั้งหมด |
| Python/Thonny | โอเพนซอร์ส ใช้สอนได้ | ไม่มีข้อกังวลที่พบ (ยังไม่ได้อ่านสัญญาอนุญาตฉบับเต็ม) |
| ใบงาน/สไลด์ในโฟลเดอร์นี้ | เขียนใหม่ทั้งหมด | ห้ามคัดลอกจากเอกสาร HQ/หนังสือแฟรนไชส์อื่น |
| ใช้ชื่อแบรนด์ Bright Up Kids กับคอร์สนี้ | ต้องได้ HQ อนุญาต | ถาม HQ ก่อนโฆษณา |
