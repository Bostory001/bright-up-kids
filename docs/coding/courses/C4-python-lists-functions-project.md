# ส่วนผู้สอน

## ภาพรวม
- แนวคิดหลัก: list, for ผ่าน list, dictionary (เบื้องต้น), ฟังก์ชัน (`def`, พารามิเตอร์, `return`), การแตกปัญหา
- ย้ำแนวปฏิบัติ: ตั้งชื่อชัดเจน, ฟังก์ชันละหนึ่งหน้าที่, เขียนคอมเมนต์ `#`
- ข้อมูลส่วนตัว: โปรเจกต์ที่เก็บ "รายชื่อ" ใช้ชื่อสมมติเท่านั้น

## คาบ 1 · list
```python
fruits = ["แอปเปิล", "กล้วย", "ส้ม"]
print(fruits[0])
fruits.append("มะม่วง")
print(len(fruits))
```
- ภารกิจ: list ของเพื่อนชอบ/อาหารโปรด เพิ่ม ลบ (`remove`) และนับ
- ข้อผิดพบบ่อย: index เริ่มที่ 0 → `IndexError`

## คาบ 2 · วนซ้ำผ่าน list
```python
scores = [80, 65, 90, 72]
total = 0
for s in scores:
    total = total + s
print("เฉลี่ย", total / len(scores))
```
- ภารกิจ: หาค่ามาก/น้อย (ไม่ใช้ `max`/`min` ก่อน แล้วเทียบ)
- เฉลย: `big = scores[0]` วนเทียบแล้วเปลี่ยนเมื่อพบค่ามากกว่า

## คาบ 3 · dictionary เบื้องต้น
```python
student = {"name": "ฟ้า", "age": 13}
print(student["name"])
student["age"] = 14
```
- ใช้แบบสมุดจดคำศัพท์: คำไทย → อังกฤษ

## คาบ 4 · ฟังก์ชัน
```python
def area_rect(w, h):
    return w * h

print(area_rect(3, 4))
```
- ถามกระตุ้น: `print` ข้างในฟังก์ชัน กับ `return` ต่างกันยังไง
- ภารกิจ: ฟังก์ชันคิดเกรด/ฟังก์ชันเช็กเลขคู่เลขคี่ (`return n % 2 == 0`)

## คาบ 5 · แตกปัญหา
- กิจกรรม: เลือกโปรเจกต์ แล้วแตกเป็น 3–5 ฟังก์ชัน เขียนผังบนกระดาษ
- ตัวเลือก: ① เกมถามตอบ (list ของคำถาม) ② สมุดรายชื่อด้วย dict ③ เกมเดาคำแบบแฮงแมน

## คาบ 6–7 · ลงมือทำ
- (ทุกคาบ) 5 นาทีแรก: รายงานความคืบหน้า 1 ประโยค → 45 นาที: ลงมือ → 10 นาที: ครูสุ่มตรวจโค้ด 1 คน
- ตัวอย่างโครงเกมถามตอบ:
```python
questions = [("เมืองหลวงของไทย", "กรุงเทพ"), ("2 + 3", "5")]

def ask(q, a):
    return input(q + " = ").strip() == a

score = 0
for q, a in questions:
    if ask(q, a):
        score = score + 1
print("ได้", score, "จาก", len(questions))
```

## คาบ 8 · โชว์ + ทบทวน
- (40) นำเสนอ 4 นาที/คน: เดโม + อธิบาย 1 ฟังก์ชันที่ภูมิใจ → (10) ถาม-ตอบ → (10) ประกาศผลและเกียรติบัตร

## การประเมิน (1–3)
| เกณฑ์ | 1 | 2 | 3 |
|---|---|---|---|
| ใช้ list/dict ถูกต้อง | ผิดบ่อย | ถูกบางส่วน | ถูก และเลือกโครงสร้างเหมาะสม |
| ฟังก์ชัน | ไม่ใช้ | ใช้ 1 ตัว | ใช้ ≥ 3 ตัว มี `return` |
| โปรเจกต์ทำงานครบ | รันไม่ได้ | รันได้บางส่วน | ครบตามแผน + ทดสอบแล้ว |
| นำเสนอ/คอมเมนต์ | ไม่มี | บางส่วน | ชัดเจน |
