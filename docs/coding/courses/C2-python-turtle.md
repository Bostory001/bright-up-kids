# ส่วนผู้สอน

## ภาพรวม
- ใช้ `import turtle` ตลอดคอร์ส ชื่อ `t = turtle.Turtle()`
- เชื่อมกับ B2: ถ้าเด็กเคยวาดใน Scratch ให้เทียบ `repeat 4` ↔ `for i in range(4)`
- ย้ำเรื่อง **ย่อหน้า (indent)** — ส่วนที่อยู่ในลูปต้องเยื้องเข้าไป 4 เว้นวรรค

## คาบ 1 · เต่าตัวแรก
```python
import turtle
t = turtle.Turtle()
t.forward(100)
t.left(90)
t.forward(100)
turtle.done()
```
- ภารกิจ: วาดตัว L และตัว U · เปลี่ยนสี `t.color("red")` และความหนา `t.pensize(3)`
- ข้อผิดพบบ่อย: ตั้งชื่อไฟล์ว่า `turtle.py` จะชนกับโมดูล → ตั้งชื่ออื่น เช่น `draw1.py`

## คาบ 2 · for loop
```python
for i in range(4):
    t.forward(100)
    t.left(90)
```
- ถามกระตุ้น: `range(4)` วนกี่รอบ? ถ้าเอา `t.left(90)` ไว้นอกลูปจะเป็นอย่างไร
- ภารกิจ: สี่เหลี่ยมผืนผ้า (ใช้ลูปสลับ 2 ด้าน) และสามเหลี่ยมด้านเท่า (`range(3)`, `left(120)`)

## คาบ 3 · หลายเหลี่ยมด้วยตัวแปร
```python
sides = int(input("กี่ด้าน? "))
for i in range(sides):
    t.forward(80)
    t.left(360 / sides)
```
- เชื่อมคณิต: มุมภายนอกรวม = 360°
- ข้อผิดพบบ่อย: ไม่แปลง `input` เป็น `int` → `TypeError`

## คาบ 4 · ดาวและวงกลม
```python
for i in range(5):
    t.forward(100)
    t.left(144)      # ดาว 5 แฉก
t.circle(50)         # วงกลมรัศมี 50
```
- ถามกระตุ้น: ทำไมมุม 144 ได้ดาว (144 × 5 = 720 = หมุน 2 รอบ)

## คาบ 5 · ลวดลาย (loop ซ้อน)
```python
colors = ["red", "orange", "yellow", "green", "blue", "purple"]
t.speed(0)
for i in range(36):
    t.color(colors[i % 6])
    for j in range(4):
        t.forward(80)
        t.left(90)
    t.left(10)
```
- ข้อสังเกต: `colors[i % 6]` วนสีซ้ำ — ใช้ `%` จาก C1

## คาบ 6 · ฟังก์ชันวาดรูป + โชว์ผล
```python
def polygon(sides, size):
    for i in range(sides):
        t.forward(size)
        t.left(360 / sides)

polygon(3, 100)
polygon(6, 60)
```
- โปรเจกต์: โปสเตอร์ลายเรขาคณิตด้วย `polygon` อย่างน้อย 3 แบบ + สี
- (30) สร้าง → (20) ฉายและเล่า "สิ่งที่คิดตอนเขียน" → (10) เกียรติบัตร

## การประเมิน (1–3)
| เกณฑ์ | 1 | 2 | 3 |
|---|---|---|---|
| ใช้ `for` + `range` | ยังไม่ถูก | ถูกเมื่อมีตัวอย่าง | ถูกด้วยตนเอง |
| ย่อหน้าถูกต้อง | ผิดบ่อย | ผิดบางจุด | ถูกต้อง |
| ใช้ฟังก์ชัน | ไม่ใช้ | ใช้ตามตัวอย่าง | เขียนฟังก์ชันของตัวเอง |
