# ส่วนผู้สอน

## ภาพรวม
- ตั้งทีม 2 คน (นักออกแบบ + นักเขียนโค้ด) สลับบทบาททุกคาบ
- สอนนิสัยดี: ตั้งชื่อตัวแปร/บล็อกให้สื่อความหมาย, ใส่คอมเมนต์ (คลิกขวา → Add Comment)
- กฎโครงการ: ส่งแผนก่อนเริ่มสร้าง

## คาบ 1 · แผนโปรเจกต์
- ลำดับ: (10) ดูตัวอย่างเกมสามฉาก → (35) เขียน "เอกสารออกแบบ" 1 หน้า (ฉากเมนู / ฉากเล่น / ฉากจบ) → (15) ขอความเห็นเพื่อน
- เกณฑ์ผ่านแผน: มี 3 ฉาก, ตัวแปรอย่างน้อย 2 ตัว, 1 ฟังก์ชัน

## คาบ 2 · Broadcast: ให้ตัวละครคุยกัน
- เป้าหมาย: `broadcast` และ `when I receive`
- เฉลย: ปุ่ม "เริ่ม" `when this sprite clicked → broadcast start` · ผู้เล่น `when I receive start → show; go to x:0 y:-120`
- ข้อผิดพบบ่อย: สะกดชื่อข้อความต่างกัน (message ต้องเลือกจากรายการเดียวกัน)

## คาบ 3 · ฉากเมนู
- ภารกิจ: เมนูเริ่ม มีปุ่ม "เริ่มเกม" และ "วิธีเล่น" ใช้ broadcast เปลี่ยน Backdrop

## คาบ 4 · My Blocks (ฟังก์ชัน)
- เป้าหมาย: เข้าใจว่าฟังก์ชัน = ตั้งชื่อชุดคำสั่งเพื่อใช้ซ้ำ
- เฉลย: My Blocks → Make a Block ชื่อ `reset position` → `go to x: 0 y: -120; set score to 0` แล้วเรียกใช้ใน 2 ที่
- ถามกระตุ้น: "ถ้าต้องแก้ตำแหน่งเริ่ม ต้องแก้กี่ที่เมื่อใช้ฟังก์ชัน"

## คาบ 5 · ฟังก์ชันมีพารามิเตอร์
- เฉลย: `Make a Block "spawn enemy (x)"` ใช้ `go to x: (x) y: 180` เรียก `spawn enemy 50` และ `spawn enemy -100`

## คาบ 6 · Clone (ทำสำเนาตัวละคร)
- เป้าหมาย: ศัตรู/ของตกหลายตัวด้วย `create clone of myself`
- เฉลย: `when flag clicked: hide; forever { create clone of myself; wait 1 seconds }` และ `when I start as a clone: go to x: (random) y: 180; show; repeat until y < -170 { change y by -4 }; delete this clone`
- ข้อผิดพบบ่อย: ลืม `delete this clone` → เกมค้าง

## คาบ 7 · ทดสอบ แก้บั๊ก และปรับแต่ง
- ลำดับ: (20) แลกเกมเพื่อนทดสอบ จดบั๊ก 3 ข้อ → (35) แก้ → (5) บันทึก
- ใช้ใบ "บันทึกบั๊ก" ในส่วนผู้เรียน

## คาบ 8 · เทศกาลเกม
- ลำดับ: (35) โชว์ เล่าสิ่งที่ยากที่สุด → (15) โหวต "เกมสร้างสรรค์" และ "โค้ดสะอาด" → (10) เกียรติบัตร

## การประเมิน (1–3)
| เกณฑ์ | 1 | 2 | 3 |
|---|---|---|---|
| Broadcast / เปลี่ยนฉาก | ไม่ใช้ | ใช้ 1 จุด | ใช้ครบเมนู–เล่น–จบ |
| My Blocks | ไม่ใช้ | ฟังก์ชัน 1 ตัว | ใช้ 2+ ตัว/มีพารามิเตอร์ |
| ผลงานสมบูรณ์และมีเอกสาร | ขาดเอกสาร | มีเอกสาร ผลงานไม่ครบ | ครบทั้งสอง + คอมเมนต์ในโค้ด |

# ส่วนผู้เรียน (ใบงาน)

## คาบ 1 · เอกสารออกแบบ
- ชื่อเกม ______ · เล่นกับ ______ คน
- ฉาก 1 เมนู: มีปุ่มอะไรบ้าง ______
- ฉาก 2 เล่น: ตัวละคร ______ ตัวแปร ______
- ฉาก 3 จบ: แสดงอะไร ______
- ฟังก์ชันที่จะสร้าง: ______
เช็ก: ☐ ครบ 3 ฉาก ☐ ตัวแปร ≥ 2 ☐ ฟังก์ชัน ≥ 1

## คาบ 2 · broadcast
ทดลอง: ปุ่ม "เริ่ม" ส่งข้อความ `start` → ตัวละครผู้เล่นปรากฏ
เช็ก: ☐ ส่งข้อความได้ ☐ ตัวละครรับแล้วทำงาน

## คาบ 3 · เมนู
เช็ก: ☐ ปุ่มเริ่มเกม ☐ ปุ่มวิธีเล่น ☐ เปลี่ยน Backdrop เมื่อกด

## คาบ 4 · สร้างฟังก์ชันแรก
1. My Blocks → Make a Block → `reset position`
2. ใส่คำสั่งตั้งตำแหน่งและคะแนน
3. เรียกใช้ในโค้ดอย่างน้อย 2 ที่
เช็ก: ☐ ฟังก์ชันทำงาน ☐ เรียกใช้ซ้ำ 2 ที่

## คาบ 5 · ฟังก์ชันมีพารามิเตอร์
ลองสร้าง `spawn enemy (x)` แล้วเรียกด้วย 3 ค่า
เช็ก: ☐ ศัตรูโผล่ 3 ตำแหน่ง

## คาบ 6 · Clone
เช็ก: ☐ มีของตกหลายชิ้นพร้อมกัน ☐ มี `delete this clone`
