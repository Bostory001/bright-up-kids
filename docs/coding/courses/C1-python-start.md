# ส่วนผู้สอน

## ภาพรวม
- ติดตั้งก่อนวันสอนทั้งห้อง ทดสอบ `print("hello")` ให้ผ่าน
- ทุกคาบเริ่มด้วย "ทำนายผลก่อนรัน" (predict → run → explain)
- ย้ำ 3 เรื่องที่ทำให้ error บ่อย: เครื่องหมายคำพูดไม่ครบ, ย่อหน้า (indent), ตัวพิมพ์เล็ก/ใหญ่ (Python แยกตัวพิมพ์)
- ภาษาไทยในข้อความ `print` ใช้ได้ (Python 3 รองรับ Unicode)

## คาบ 1 · โปรแกรมแรก
- เป้าหมาย: ติดตั้ง/เปิด Thonny, ใช้ `print`, อ่าน error message
- ตัวอย่าง:
```python
print("สวัสดี Python")
print("ฉันชื่อมะนาว")
```
- ภารกิจ: พิมพ์ชื่อ ชั้น และงานอดิเรก 3 บรรทัด · จงใจทำให้ผิด เช่น ลบเครื่องหมายคำพูด แล้วอ่านข้อความ error ด้วยกัน
- ข้อผิดพบบ่อย: ใช้ `Print` ตัว P ใหญ่ → `NameError`

## คาบ 2 · ตัวแปร
- เป้าหมาย: กำหนดตัวแปร ตั้งชื่อดี ชนิดข้อมูล (ข้อความ/จำนวนเต็ม/ทศนิยม)
```python
name = "มะนาว"
age = 12
height = 1.45
print(name, "อายุ", age, "ปี")
print(age + 1)
```
- ถามกระตุ้น: `"5" + "3"` กับ `5 + 3` ต่างกันยังไง (ผล "53" กับ 8)
- ข้อผิดพบบ่อย: ตั้งชื่อตัวแปรขึ้นต้นด้วยตัวเลข / มีช่องว่าง

## คาบ 3 · รับค่าจากผู้ใช้
```python
name = input("ชื่ออะไร? ")
print("สวัสดี", name)
```
- สำคัญ: `input()` ได้ข้อความเสมอ → ต้องแปลงเป็นตัวเลข:
```python
a = int(input("เลขตัวแรก: "))
b = int(input("เลขตัวที่สอง: "))
print("ผลบวก =", a + b)
```
- ข้อผิดพบบ่อย: `TypeError: can only concatenate str...` เมื่อลืม `int()`; ผู้ใช้พิมพ์ตัวอักษรแล้ว `ValueError` (แจ้งไว้ว่าจะจัดการใน C3)

## คาบ 4 · ตัวดำเนินการ
- เป้าหมาย: `+ - * / // % **`
```python
print(17 / 5)    # 3.4
print(17 // 5)   # 3
print(17 % 5)    # 2
print(2 ** 3)    # 8
```
- กิจกรรม: "ตู้หยอดเหรียญทอนเงิน" ใช้ `//` และ `%` ทอนเป็นแบงก์/เหรียญ

## คาบ 5 · โปรเจกต์เล็ก: เครื่องคิดเลขค่าอาหาร
- ข้อกำหนด: รับราคาอาหาร จำนวนคน → คำนวณค่าบริการ 10% และหารต่อคน
```python
price = float(input("ราคาอาหารรวม: "))
people = int(input("จำนวนคน: "))
total = price * 1.10
print("คนละ", round(total / people, 2), "บาท")
```
- ข้อผิดพบบ่อย: หารด้วย 0 เมื่อ people = 0 (ชี้ให้เห็นว่าต้องมีเงื่อนไข → C3)

## คาบ 6 · โชว์และทบทวน
- (30) นำเสนอ 3 นาที/คน หรือคู่ → (15) Quiz 5 ข้อ (ดูเฉลยด้านล่าง) → (15) สรุปและเกียรติบัตร
- เฉลย Quiz: ① `print("a" + "b")` → ab ② `7 // 2` → 3 ③ `7 % 2` → 1 ④ `int("12") + 1` → 13 ⑤ `type(3.5)` → float

## การประเมิน (1–3)
| เกณฑ์ | 1 | 2 | 3 |
|---|---|---|---|
| ตัวแปรและชนิดข้อมูล | สับสน | ใช้ถูกบางส่วน | ใช้ถูก อธิบาย `int`/`str` ได้ |
| รับค่าและคำนวณ | ต้องช่วย | ทำได้เมื่อมีตัวอย่าง | ทำเองได้ถูกต้อง |
| อ่านและแก้ error | ไม่อ่าน | อ่านแล้วแก้ได้เมื่อแนะนำ | อ่านและแก้เอง |
