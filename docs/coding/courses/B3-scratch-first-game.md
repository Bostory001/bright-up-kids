# ส่วนผู้สอน

## ภาพรวม
- เกมที่สร้างตลอดคอร์ส: เกมเก็บแอปเปิลที่ตกลงมา (ตัวละครผู้เล่นขยับซ้าย–ขวา)
- แนวคิดหลัก: ตัวแปร (variable), เงื่อนไข (if), ตัวเลขสุ่ม (random), สถานะจบเกม
- เก็บงานทุกคาบ: เด็กบันทึกไฟล์ใหม่ชื่อ `game-v1`, `v2`… เผื่อแก้ผิด

## คาบ 1 · ออกแบบเกม
- เป้าหมาย: เขียนกติกาเกม 3 ข้อ
- ลำดับ: (15) เล่นเกมตัวอย่างครู → (30) วาดผังเกม (ตัวละคร เป้าหมาย กติกา) → (15) เล่าให้เพื่อนฟัง
- ตัวอย่างกติกา: ① เก็บแอปเปิล +1 คะแนน ② พลาดแอปเปิล เสียชีวิต 1 ③ ชีวิตหมด = จบเกม

## คาบ 2 · ผู้เล่นเคลื่อนที่
- เฉลย:
```
when right arrow key pressed → change x by 10
when left arrow key pressed → change x by -10
```
- ข้อผิดพบบ่อย: ตัวละครหลุดขอบ → ใช้ `if on edge, bounce` หรือจำกัดค่า x

## คาบ 3 · แอปเปิลตก
- เฉลย:
```
when flag clicked
go to x: (pick random -200 to 200) y: 180
forever
  change y by -5
  if y position < -170 then
    go to x: (pick random -200 to 200) y: 180
```

## คาบ 4 · ตัวแปร: คะแนน
- เป้าหมาย: สร้างตัวแปร `score` เริ่มที่ 0 และบวกเมื่อแตะ
- เฉลย: `when flag clicked → set score to 0` · ในลูปแอปเปิล `if touching ผู้เล่น? then change score by 1; go to … y: 180`
- ถามกระตุ้น: "ถ้าลืม set score to 0 ตอนเริ่ม จะเกิดอะไรในเกมรอบที่สอง"

## คาบ 5 · ตัวแปร: ชีวิต
- เฉลย: สร้าง `lives` ตั้งเป็น 3 · เมื่อแอปเปิลตกพื้น `change lives by -1`
- ข้อผิดพบบ่อย: ลดชีวิตซ้ำหลายรอบต่อ 1 แอปเปิล → ย้ายแอปเปิลกลับด้านบนทันทีหลังลดชีวิต

## คาบ 6 · จบเกม
- เป้าหมาย: ใช้ `if lives = 0` → `say จบเกม` + `stop all`
- เฉลย: ใน forever `if lives = 0 then say "จบเกม" for 2 seconds; stop all`

## คาบ 7 · ปรับสมดุลและตกแต่ง
- ลำดับ: (15) ให้เพื่อนเล่นแล้วบอกว่ายากไป/ง่ายไป → (35) ปรับความเร็ว/จำนวนชีวิต/เสียง → (10) บันทึก
- ข้อควรสอน: ผู้ทดสอบ (playtester) ช่วยเจอบั๊กที่เจ้าของเกมมองไม่เห็น

## คาบ 8 · เทศกาลเกม
- ลำดับ: (40) เด็กเล่นเกมเพื่อนคนละ 3 เกม + ให้คะแนนติดดาว → (10) ครูสรุป → (10) เกียรติบัตร

## การประเมิน (1–3)
| เกณฑ์ | 1 | 2 | 3 |
|---|---|---|---|
| ตัวแปรคะแนน/ชีวิตทำงาน | ไม่ทำงาน | ทำงาน 1 ตัว | ทำงานทั้ง 2 ตัว |
| เงื่อนไข (if) ถูกต้อง | ผิดบ่อย | ผิดบางจุด | ถูก และอธิบายได้ |
| เกมเล่นได้ครบ เริ่ม–จบ | เล่นไม่จบ | เล่นได้แต่ยังไม่มีจุดจบ | มีจุดจบและเริ่มใหม่ได้ |

# ส่วนผู้เรียน (ใบงาน)

## คาบ 1 · ผังเกมของฉัน
- ชื่อเกม: ________
- ผู้เล่นคือ: ________ ควบคุมด้วย: ________
- ต้องเก็บ/หลบอะไร: ________
- ชนะ/แพ้เมื่อ: ________
เช็ก: ☐ กติกาอย่างน้อย 3 ข้อ

## คาบ 2 · ขยับผู้เล่น
`when right arrow key pressed → change x by 10`
`when left arrow key pressed → change x by -10`
เช็ก: ☐ ขยับซ้าย–ขวาได้

## คาบ 3 · ของตกลงมา
ใช้โค้ดจากครู: ตกจากบน ถึงพื้นแล้วกลับไปบนที่ตำแหน่งสุ่ม
เช็ก: ☐ แอปเปิลตกลงมา ☐ ตกคนละตำแหน่งทุกครั้ง

## คาบ 4 · นับคะแนน
1. Variables → Make a Variable → ชื่อ `score`
2. `set score to 0` ตอนเริ่ม
3. แตะผู้เล่น → `change score by 1`
ท้าทาย: ให้คะแนนเพิ่ม 2 เมื่อเก็บแอปเปิลสีทอง
เช็ก: ☐ คะแนนเพิ่มเมื่อเก็บ ☐ เริ่มเกมใหม่คะแนนกลับเป็น 0

## คาบ 5 · ชีวิต
สร้างตัวแปร `lives` = 3 ลด 1 เมื่อพลาด
เช็ก: ☐ ชีวิตลดทีละ 1 เมื่อพลาด

## คาบ 6 · จบเกม
`if lives = 0` → พูด "จบเกม" แล้วหยุด
เช็ก: ☐ เกมจบเมื่อชีวิตหมด ☐ ลองเล่นใหม่ได้

## คาบ 7 · ปรับเกม
ให้เพื่อน 2 คนเล่น แล้วจด: ง่ายไป ☐ พอดี ☐ ยากไป ☐ — ฉันจะแก้: ________

## คาบ 8 · เทศกาลเกม
ให้ดาว 1–5 กับเกมเพื่อน 3 เกม พร้อมเหตุผล 1 ข้อ: "ฉันชอบ…เพราะ…"
