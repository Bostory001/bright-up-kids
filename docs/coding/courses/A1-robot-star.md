> แทนที่ฉบับแรก (กระดาษอย่างเดียว) — ฉบับนี้ผสม **กิจกรรมร่างกาย/กระดาษ** กับ **เว็บเกมประกอบ** ที่ทำไว้แล้ว: `web/public/coding/a1/index.html` (เปิดที่ `/coding/a1/index.html` บนเว็บของสถาบัน)

| รายการ | รายละเอียด |
|---|---|
| ชั้น | ป.1–2 (อายุ 6–8) |
| ความยาว | 8 คาบ × 60 นาที |
| เครื่องมือ | ตารางเทปกาวบนพื้น 5×5 + การ์ดลูกศร · **เกม "หุ่นยนต์หาดาว"** (เว็บ ไม่ต้องล็อกอิน ไม่ต้องติดตั้ง) · แท็บเล็ตหรือคอม 1 เครื่อง/2 คน |
| พื้นฐานที่ต้องมี | ไม่ต้องอ่านคล่อง (ใบงานเป็นภาพ/ลูกศร) |

| เชื่อมคอร์สต่อ | A2 (ScratchJr) |

## เปลี่ยนจากฉบับแรกอย่างไร (แก้ช่องโหว่)
- ใช้ **ลูกศรทิศทางแบบเดียวตลอด** (↑ ↓ ← →) ไม่มีคำสั่ง "เลี้ยวซ้าย/ขวา" ที่ทำให้เด็กสับสน หุ่นยนต์เดินไปทางลูกศรโดยไม่ต้องหมุนตัว
- ทุกคาบ = **ร่างกาย → กระดาษ → เกม** เด็กได้ลองคิดก่อนกดจริง และมีผลลัพธ์ที่เห็นทันทีในเกม
- ใบงานเป็นภาพ ไม่ต้องอ่านข้อความยาว
- มีด่านล่าบั๊ก และด่านทำซ้ำที่ **จำกัดจำนวนการ์ด** บังคับให้ต้องคิดหาวิธีสั้นลง (ได้ดาวเพิ่มเมื่อใช้การ์ดน้อย)
- ผลงานปลายคอร์สคือ **เขาวงกตของเด็กเอง** ส่งเป็นลิงก์ให้ผู้ปกครอง/เพื่อนเล่นได้
- มีแบบวัดก่อน–หลังเรียน และใบสรุปสำหรับผู้ปกครอง

## เกมประกอบ — ใช้ตรงไหน
| ด่านในเกม | คืออะไร | ใช้ในคาบ |
|---|---|---|
| 1–4 | ลำดับคำสั่ง เดินไปดาว | 2 |
| 5–7 | กำแพง ต้องวางแผน | 3 |
| 8–10 (ล่าบั๊ก) | มีโปรแกรมที่ผิดให้แก้ | 4 |
| 11–13 (ทำซ้ำ) | จำกัดการ์ด ต้องใช้ 🔁 | 6 |
| 14–15 (ล่าบั๊กในลูป) | แก้จำนวนรอบ | 7 |
| สร้างเขาวงกต | ออกแบบ → ลองเล่น → คัดลอกลิงก์ | 8 |

ดาว ★ ต่อด่านขึ้นกับจำนวนการ์ด (ใช้ไม่เกินค่ามาตรฐาน = 3 ดาว) ความคืบหน้าเก็บในเครื่องนั้นเท่านั้น ไม่ส่งข้อมูลเด็กไปไหน

## แบบวัดก่อน–หลัง (ทำคาบ 1 และคาบ 8 ใช้ชุดเดียวกันเปรียบเทียบ)
ครูอ่านโจทย์ เด็กตอบด้วยภาพ/ชี้ (ไม่เขียน):
1. ตัวละครอยู่ช่องซ้ายล่าง ดาวอยู่ข้างบน 2 ช่อง → ลูกศรชุดไหนถูก (เลือกจาก 3 ชุด)
2. โปรแกรม → → ↓ ไปถึงดาวที่ไหน (ชี้ช่อง)
3. โปรแกรมมีบั๊ก 1 จุด ชี้ว่าการ์ดไหนผิด
4. → → → → → เขียนให้สั้นได้ไหม (บอก "ทำซ้ำ 5 ครั้ง [→]")
คะแนน 0–4 ครูจดไว้ ใช้รายงานผู้ปกครอง

# ส่วนผู้สอน — รายนาทีทั้ง 8 คาบ

**ของที่ใช้ทุกคาบ:** ตารางเทป 5×5 บนพื้น (ช่อง ≈ 40 ซม.) · การ์ดลูกศร 4 สี คนละชุด (↑ ฟ้า ↓ ส้ม ← ม่วง → เขียว สีตรงกับในเกม) · สติกเกอร์ดาว · แท็บเล็ต/คอมคู่ละ 1 เครื่อง (เปิดเว็บเกมไว้ล่วงหน้า)
**ติดตามเวลา:** 5 นาทีพักทุกคาบ · ถ้าเด็กหมดสมาธิให้ตัดช่วง "ท้าทาย" ออกก่อน
