# ส่วนผู้สอน

## ภาพรวม
- แนวคิดหลัก: เงื่อนไข (`if/elif/else`), ตัวเปรียบเทียบ (`== != < > <= >=`), `while`, ตรรกะ `and/or/not`, `try/except` เบื้องต้น
- ข้อผิดพบบ่อย: ใช้ `=` แทน `==`, ลืม `:`, ย่อหน้าผิด, ลูป `while` ไม่จบ (หยุดด้วย Ctrl+C หรือปุ่ม Stop ใน Thonny)

## คาบ 1 · if / else
```python
score = int(input("คะแนน: "))
if score >= 50:
    print("ผ่าน")
else:
    print("ไม่ผ่าน")
```
- ภารกิจ: ตรวจอายุเข้าเครื่องเล่น (สูง/อายุตามเกณฑ์)

## คาบ 2 · elif และเกรด
```python
if score >= 80:
    grade = "A"
elif score >= 70:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "ต้องปรับปรุง"
print("เกรด", grade)
```
- ถามกระตุ้น: ถ้าสลับลำดับเงื่อนไข ผลจะเป็นอย่างไร (ตรวจจากมากไปน้อยเท่านั้น)

## คาบ 3 · and / or / not
```python
age = int(input("อายุ: "))
has_ticket = input("มีตั๋วไหม (y/n): ") == "y"
if age >= 7 and has_ticket:
    print("เข้าได้")
```
- กิจกรรม: ตารางค่าความจริง (truth table) ด้วยปากกา แล้วทดสอบด้วยโค้ด

## คาบ 4 · while
```python
count = 1
while count <= 5:
    print(count)
    count = count + 1
```
- ภารกิจ: นับถอยหลัง 10→1 แล้วพิมพ์ "ปล่อยจรวด!"
- ข้อผิดพบบ่อย: ลืม `count = count + 1` → วนไม่รู้จบ

## คาบ 5 · เกมทายเลข
```python
import random
secret = random.randint(1, 20)
tries = 0
while True:
    guess = int(input("ทายเลข 1-20: "))
    tries = tries + 1
    if guess == secret:
        print("ถูกต้อง! ใช้", tries, "ครั้ง")
        break
    elif guess < secret:
        print("น้อยไป")
    else:
        print("มากไป")
```
- ภารกิจ: จำกัดจำนวนครั้ง, ขยายช่วงเลข, ปรับคำใบ้
- ถ้าใส่ตัวอักษรจะ error → สอน `try/except`:
```python
try:
    guess = int(input("ทายเลข: "))
except ValueError:
    print("กรุณาพิมพ์ตัวเลข")
    continue
```
(ใช้ภายในลูป `while`)

## คาบ 6 · โปรเจกต์ + โชว์ผล
- ตัวเลือก: เกมทายเลขปรับแต่ง / เกมเป่ายิ้งฉุบ / แบบทดสอบ 5 ข้อมีคะแนน
- (35) สร้าง → (15) แลกเล่น → (10) สรุป + เกียรติบัตร

## การประเมิน (1–3)
| เกณฑ์ | 1 | 2 | 3 |
|---|---|---|---|
| เงื่อนไขถูกต้อง | ผิดบ่อย | ถูกบางส่วน | ถูก ใช้ elif/and/or ได้ |
| ลูป while จบได้ | ไม่จบ | จบเมื่อแนะนำ | ออกแบบเงื่อนไขหยุดเอง |
| จัดการข้อมูลผิด | ไม่จัดการ | จัดการได้เมื่อแนะนำ | ใช้ try/except เอง |

# ส่วนผู้เรียน (ใบงาน)

## คาบ 1 · ผ่านหรือไม่ผ่าน
เขียนโปรแกรมรับคะแนนแล้วบอกผ่าน (≥ 50) หรือไม่ผ่าน
ท้าทาย: ถ้าคะแนนเกิน 100 ให้บอกว่า "คะแนนไม่ถูกต้อง"
เช็ก: ☐ ใช้ `if/else` ถูกต้อง ☐ ย่อหน้าถูก

## คาบ 2 · เกรด
เติมโปรแกรมเกรด A B C D (ให้เกณฑ์ของตัวเอง) ทดสอบด้วยคะแนน 85, 72, 55, 30
เช็ก: ☐ ทดสอบครบ 4 ค่า ☐ ถูกทุกค่า
