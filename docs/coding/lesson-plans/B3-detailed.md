## ก่อนเริ่มคอร์ส (ครูเตรียมครั้งเดียว)
- ทำเกมต้นแบบ "เก็บแอปเปิล" เสร็จแล้ว 1 ไฟล์ (`demo-final.sb3`) และไฟล์เริ่มต้นแต่ละคาบ (`demo-v1…v7`) เผื่อเด็กตามไม่ทัน
- ตัวละคร: ผู้เล่น = ตะกร้า (วาดเองในโปรแกรมวาดของ Scratch), ของตก = แอปเปิล · ใช้ภาพที่มากับ Scratch หรือวาดเอง ไม่ดึงจากเน็ต
- ตั้งกฎห้อง: ชื่อไฟล์ = `game-ชื่อเล่น-vN` · บันทึกท้ายทุกคาบ · ห้ามกดแก้โปรเจกต์เพื่อน
- ค่าที่ใช้บ่อย: เวที x −240..240, y −180..180

## รูปแบบเวลามาตรฐานของทุกคาบ
| นาที | กิจกรรม |
|---|---|
| 0–5 | เช็กอิน + ทบทวน 1 คำถาม |
| 5–15 | ครูสาธิต (เด็กดูก่อน ยังไม่แตะเมาส์) |
| 15–45 | เด็กลงมือ (ครูเดินตรวจ) |
| 45–55 | โชว์/แลกเล่น |
| 55–60 | สรุป + บันทึก + ตั๋วออกจากห้อง (exit ticket) |

## คาบ 1 · ออกแบบเกมบนกระดาษ
**จุดประสงค์:** (1) บอกองค์ประกอบเกม 4 อย่าง: ผู้เล่น เป้าหมาย กติกา ฉากจบ (2) เขียนกติกาของเกมตัวเอง 3 ข้อ
**เตรียม:** ใบงานผังเกม · ดินสอสี · เครื่องฉายเกมต้นแบบ
**ดำเนินการ**
1. (0–5) ถาม: "เกมโปรดของเธอคืออะไร ใครชนะ ใครแพ้ได้ยังไง" ให้ 3 คนตอบ
2. (5–15) เล่นเกมต้นแบบให้ดู 2 รอบ แล้วถามทีละข้อ: ใครคือผู้เล่น? ได้คะแนนตอนไหน? แพ้เมื่อไร? เขียนคำตอบเป็น 4 หัวข้อบนกระดาน
3. (15–40) เด็กออกแบบเกมของตัวเอง (ไม่ต้องเปิดคอม) ตามใบงาน: วาดหน้าจอ ตัวละคร ปุ่มควบคุม เขียนกติกา 3 ข้อ
4. (40–55) จับคู่เล่าเกมให้เพื่อนฟัง เพื่อนถาม 1 คำถาม "ถ้า…จะเกิดอะไรขึ้น"
5. (55–60) exit ticket: เขียน 1 ประโยค "เกมฉันชนะเมื่อ…"
**ถามกระตุ้น:** "เกมที่ง่ายมากเล่นสนุกไหม ทำไม"
**ถ้าเด็กเร็ว:** ออกแบบด่านที่ 2 · **ถ้าเด็กช้า:** ใช้แบบเกมของครู แต่เปลี่ยนตัวละคร/ธีม
**เกณฑ์ผ่าน:** ผังมีครบ 4 หัวข้อ
**🖥 ออนไลน์:** ส่งใบงานเป็นไฟล์ล่วงหน้า ให้เด็กถ่ายรูปส่งท้ายคาบ

## คาบ 2 · ผู้เล่นเคลื่อนที่
**จุดประสงค์:** (1) ใช้ `when [key] pressed` ขยับตัวละคร (2) อธิบายว่า x คือซ้าย–ขวา
**เตรียม:** ไฟล์เริ่มต้น `v1` (ฉากหลัง + ตะกร้า)
**ดำเนินการ**
1. (0–5) ทบทวน: "ปุ่มลูกศรทำให้อะไรเกิดขึ้นในเกมต้นแบบ" เด็กชี้บนจอ
2. (5–15) สาธิตสด: เพิ่ม `when right arrow key pressed` → `change x by 10` พูดออกเสียงขณะลาก "ฉันเปลี่ยน x ทีละ 10 ไปทางขวา" · ทดลองเปลี่ยนเป็น 30 ให้เห็นความเร็วเปลี่ยน
3. (15–35) เด็กทำตาม + ลองเอง: ทำปุ่มซ้าย · จำกัดไม่ให้ออกนอกเวที
4. (35–50) ท้าทาย: ทำให้ตะกร้าเคลื่อนไหวนุ่มขึ้นด้วย `forever + if key pressed?`
5. (50–60) แลกเล่นกับเพื่อน · exit ticket: "change x by -10 ทำอะไร"
**ข้อผิดพบบ่อยและวิธีแก้**
- ตะกร้าไปทางผิด → เช็กเครื่องหมาย + หรือ −
- กดค้างแล้วกระตุก → เป็นปกติ ใช้ท้าทายข้อ 4
**เฉลยท้าทาย:**
```
when flag clicked
forever
  if key right arrow pressed? then change x by 8
  if key left arrow pressed? then change x by -8
```
**🖥 ออนไลน์:** ให้เด็กโชว์ผ่านแชร์หน้าจอเฉพาะแท็บ Scratch

## คาบ 3 · แอปเปิลตก
**จุดประสงค์:** (1) ใช้ `forever` + `change y by` (2) ใช้ `pick random` ให้ตำแหน่งสุ่ม
**ดำเนินการ**
1. (0–5) ทบทวนคาบก่อน: "y คือขึ้น–ลงใช่ไหม ถ้าต้องการให้ตกต้อง y เป็นยังไง"
2. (5–15) สาธิต: `go to x: ? y: 180` → `forever { change y by -5 }` ลองรัน เห็นแอปเปิลตกแล้วหายลงข้างล่าง → ถามว่า "ทำอย่างไรให้กลับมาใหม่" ให้เด็กเสนอ
3. (15–40) เด็กทำ: เพิ่ม `if y position < -170 then go to x: (pick random -200 to 200) y: 180`
4. (40–55) ปรับความเร็ว: ทดลอง −3, −8 อธิบายผลต่อความยาก
5. (55–60) exit ticket: เลขสุ่มช่วยเกมอย่างไร
**เฉลย**
```
when flag clicked
go to x: (pick random -200 to 200) y: 180
forever
  change y by -5
  if y position < -170 then
    go to x: (pick random -200 to 200) y: 180
```
**ข้อผิดพบบ่อย:** ใช้ `=` แทน `<` ทำให้ไม่ทำงาน (y แทบไม่เคยเท่ากับ −170 พอดี) · ลืมใส่เครื่องหมายลบ
**ถ้าเด็กเร็ว:** เพิ่มแอปเปิลสีทอง

## คาบ 4 · ตัวแปร: คะแนน
**จุดประสงค์:** (1) อธิบายตัวแปรว่า "กล่องเก็บตัวเลขที่เปลี่ยนได้" (2) สร้าง `score` และบวกเมื่อเก็บแอปเปิล
**เตรียม:** กล่องกระดาษ + กระดาษโน้ต 3 แผ่น สำหรับอธิบายตัวแปรด้วยของจริง
**ดำเนินการ**
1. (0–5) กิจกรรมกล่อง: เขียน "0" ใส่กล่อง "คะแนน" ให้เด็กเปลี่ยนค่าตามเสียงครู "+1" "+1" → คะแนนคือกล่องที่เปลี่ยนค่าได้
2. (5–15) สาธิต: Variables → Make a Variable `score` (for all sprites) · `set score to 0` ตอนเริ่ม · ในลูปแอปเปิล `if touching ตะกร้า? then change score by 1; go to x: (random) y: 180`
3. (15–40) เด็กทำตาม และทดสอบ 3 รอบ
4. (40–55) "ตามหาบั๊ก" จับคู่ตรวจ: ถ้าคะแนนเพิ่มทีละหลายครั้งต่อ 1 แอปเปิล → ต้องย้ายแอปเปิลกลับด้านบนทันที
5. (55–60) exit ticket: ถ้าไม่ `set score to 0` ตอนเริ่ม จะเกิดอะไร
**เฉลย:**
```
when flag clicked
set score to 0
go to x: (pick random -200 to 200) y: 180
forever
  change y by -5
  if touching ตะกร้า? then
    change score by 1
    go to x: (pick random -200 to 200) y: 180
  if y position < -170 then
    go to x: (pick random -200 to 200) y: 180
```
**ถ้าเด็กเร็ว:** แสดงข้อความเมื่อคะแนนถึง 10

## คาบ 5 · ตัวแปร: ชีวิต
**จุดประสงค์:** (1) สร้าง `lives` ตั้งค่า 3 (2) ลดเมื่อพลาด และใช้ตัวแปรสองตัวร่วมกัน
**ดำเนินการ**
1. (0–5) ทบทวน: ตัวแปรคืออะไร? เกมตอนนี้แพ้ได้ไหม (ยังไม่ได้)
2. (5–15) สาธิต: `lives` = 3 · เมื่อแอปเปิลตกพื้น `change lives by -1` แล้วค่อยย้ายกลับด้านบน
3. (15–40) เด็กทำ + ทดสอบ: ปล่อยให้พลาด 3 ครั้ง ดูว่าลดจริง
4. (40–55) ปรับสมดุล: ทดลองเริ่มด้วยชีวิต 5 หรือ 1 สังเกตความยาก
5. (55–60) exit ticket
**ข้อผิดพบบ่อย:** ชีวิตลดต่อเนื่องไม่หยุดเพราะลืมย้ายแอปเปิลกลับ → ย้ำลำดับ: ลดชีวิต → ย้ายกลับ
**เฉลย (ส่วนตกพื้น):**
```
if y position < -170 then
  change lives by -1
  go to x: (pick random -200 to 200) y: 180
```

## คาบ 6 · จบเกม
**จุดประสงค์:** (1) เขียนเงื่อนไขจบเกม (2) ทำให้เริ่มใหม่ได้ถูกต้อง
**ดำเนินการ**
1. (0–5) ทบทวน: เล่นแล้วชีวิตเหลือ 0 เกมยังเล่นต่อ → ปัญหา
2. (5–15) สาธิต: ในลูป `if lives < 1 then say จบเกม for 2 seconds; stop all` (ใช้ `<` ปลอดภัยกว่า `=`)
3. (15–40) เด็กทำ ทดสอบ "เล่นใหม่": กดธงเขียวซ้ำแล้วค่าต้องรีเซ็ต
4. (40–55) เพิ่มฉากจบ: สร้างข้อความ "คะแนนของคุณ: …" ด้วย `join`
5. (55–60) exit ticket
**หมายเหตุ:** ถ้า `stop all` ทำให้ข้อความไม่ทันโชว์ ให้ `say … for 2 seconds` ก่อน `stop all`
**ถ้าเด็กเร็ว:** ทำปุ่ม "เล่นใหม่"

## คาบ 7 · ทดสอบ ปรับสมดุล ตกแต่ง
**จุดประสงค์:** (1) ให้ข้อเสนอแนะจากการทดสอบ (2) แก้บั๊ก/ปรับความยาก (3) ตกแต่งเสียง/ฉาก
**ดำเนินการ**
1. (0–5) แนะนำบทบาท "ผู้ทดสอบเกม": เล่นแล้วจดสิ่งที่ชอบ 1 · สิ่งที่สับสน 1 · บั๊ก 1
2. (5–25) หมุนเวียน: แต่ละคนเล่นเกมเพื่อน 2 เกม คนละ 5 นาที จดตามแบบฟอร์ม
3. (25–50) เจ้าของเกมแก้ตามข้อเสนอ + เพิ่มเสียง (`play sound`) และ Backdrop
4. (50–60) เล่าว่าแก้อะไรไปบ้าง 1 ประโยค
**ข้อควรสอน:** รับคำวิจารณ์ด้วยคำพูดที่สุภาพ — ให้ใช้ประโยค "ฉันชอบ… ฉันงงตรง… ลองเพิ่ม…"

## คาบ 8 · เทศกาลเกม
**จุดประสงค์:** (1) นำเสนอผลงาน (2) ประเมินตนเองและเพื่อน
**ดำเนินการ**
1. (0–5) ซ้อมพูด 1 ประโยค "เกมฉันชื่อ… เล่นโดย… ตัวแปรที่ใช้คือ…"
2. (5–40) สถานีเกม: จัดโต๊ะ/ห้องย่อยให้ทุกคนเล่น ≥ 3 เกม ให้ดาวพร้อมเหตุผล
3. (40–50) ครูคัดเกมเด่น 3 เกมฉายหน้าชั้น (ให้ทุกคนมีโอกาสในรอบหน้า)
4. (50–60) ประเมินตนเอง (☐ ตัวแปรทำงาน ☐ if ถูก ☐ เกมเล่นจนจบ) · แจกเกียรติบัตร · ถามว่าอยากต่อ B4 หรือไม่
**🖥 ออนไลน์:** ใช้ห้องย่อยหมุนเวียน หรือให้เด็กแชร์ลิงก์ไฟล์ให้ครูรวมเล่นหน้าจอเดียว
