# Key takeaways

## 1. โครงสร้างหลักสูตร
- แบ่งตามช่วงวัย 3 สาย: **A** (ป.1–2: คิดเป็นขั้นตอน/ScratchJr) → **B** (ป.3–6: Scratch) → **C** (ม.1–3: Python)
- เป็น **คอร์สย่อย 6–8 คาบ** 10 คอร์ส ไม่ผูกครบเส้นทาง เด็กเข้า–ออกตามพื้นฐานได้
- ทุกคอร์สจบด้วยผลงาน (เขาวงกต/เรื่องเล่า/การ์ด/ลายผ้า/เกม/โปรเจกต์) เพราะเด็กและผู้ปกครองเห็นผลชัดและเอาไปโชว์ต่อได้

## 2. แนวคิดการสอน
- เริ่มจากการเคลื่อนไหวและกระดาษ (unplugged) แล้วค่อยไปบล็อก แล้วค่อยไปข้อความ
- วนแนวคิดเดิมในเครื่องมือใหม่: ลำดับ → ลูป → เงื่อนไข → ตัวแปร → ฟังก์ชัน
- ทุกคาบ: ทบทวน → สาธิต → ลงมือ → โชว์/ตรวจ · "ทำนายก่อนรัน" และ "บั๊กคือเรื่องปกติ"
- ประเมินแบบ rubric 3 ระดับ ไม่ใช้สอบกระดาษหนัก

## 2.1 รูปแบบการสอน
- รองรับทั้ง **ที่สถาบัน ออนไลน์สด และผสม** — B และ C เหมาะออนไลน์มาก, A ต้องมีผู้ปกครองช่วย, ห้องออนไลน์ควรเล็กลง (A ≤ 5 · B ≤ 8 · C ≤ 10 คน)
- ดูรายละเอียดที่ [ONLINE.md](ONLINE.md)

## 3. เครื่องมือ (ฟรีทั้งหมด)
- ScratchJr, Scratch, Python 3 + Thonny, Code.org (เป็นเครื่องมือเสริม) · อุปกรณ์หลักคือคอม/แท็บเล็ตและโปรเจกเตอร์
- รายละเอียดและอุปกรณ์ → [TOOLS.md](TOOLS.md)

## 4. ความเสี่ยงที่ต้องเคลียร์ก่อนขายจริง
1. **ใช้ Scratch ในคอร์สที่เก็บค่าเรียนได้หรือไม่** — ข้อมูลที่ค้นเจอขัดกัน ยังไม่ยืนยัน → อ่านเงื่อนไขจริง/ถาม Scratch Foundation เป็นลายลักษณ์อักษร
2. **เงื่อนไขเชิงพาณิชย์ของ Code.org** — ยังไม่ตรวจ
3. **ใช้ชื่อ/โลโก้ Bright Up Kids** กับคอร์สนี้ต้องได้ HQ อนุญาต
4. **PDPA เด็ก**: ใช้ชื่อเล่น ไม่สมัครบัญชีออนไลน์ถ้าไม่จำเป็น ขออนุญาตผู้ปกครองก่อนเผยแพร่ผลงาน
5. ไม่ใช้โลโก้/แมว Scratch ในสื่อการตลาด

## 5. สิ่งที่ยังไม่ได้ทำ/ไม่ได้ตรวจ (บอกตรง ๆ)
- ยังไม่ได้ **เทียบทีละตัวชี้วัด** กับเอกสาร สสวท. ฉบับจริง
- ยังไม่ได้ **ทดลองสอนกับเด็กจริง** — เวลาในแต่ละกิจกรรมเป็นค่าประมาณ ควรปรับหลังนำร่อง 1 รอบ
- ชื่อบล็อก/ปุ่มใน Scratch/ScratchJr อาจต่างตามเวอร์ชัน ครูต้องลองใช้จริงก่อนสอน
- ยังไม่ได้ **ทดลองสอนออนไลน์จริง** และยังไม่ได้เลือก/ตรวจแพลตฟอร์มวิดีโอคอล (ราคา ข้อจำกัด)
- ยังไม่มีสไลด์ประกอบ ภาพประกอบใบงาน แบบประเมินผู้ปกครอง และราคา
- โค้ด Python ตัวอย่างตรวจโดยอ่านและรันแบบสุ่ม ดูหัวข้อ "ผลตรวจ" ด้านล่าง

## 6. ขั้นถัดไปที่แนะนำ
1. เลือก 1 คอร์สนำร่อง (แนะนำ **B3** เพราะเด็ก ป.4–6 เป็นกลุ่มใหญ่ และมีผลงานเกม) สอนรอบทดลอง 3–5 คน
2. เคลียร์เรื่องลิขสิทธิ์ Scratch + ขออนุญาต HQ
3. ทำสไลด์/คลิปสอนประกอบ (ใช้สกิลทำคลิปที่มี) และตั้งราคา
4. ถ้าจะลงในระบบ ต้องเพิ่ม coding เป็นวิชาที่ 5 → วิเคราะห์ผลกระทบ `types.ts` ก่อน

## ผลตรวจ
- โค้ด Python 24 บล็อกใน C1–C4 ผ่านการตรวจ syntax ทั้งหมด (0 ผิด) และรันตัวอย่างคำนวณ (หาร/หารปัดเศษ/เศษ/ผลรวม/ค่าเฉลี่ย/ทอนเงิน) ได้ค่าตรงกับเฉลย
- โมดูล `turtle` ติดตั้งในเครื่องนี้ แต่ **ยังไม่ได้เปิดหน้าต่างวาดจริง** — ครูควรรันโค้ด C2 ในห้องเรียนจริงก่อนสอน
- โค้ดแบบบล็อกของ Scratch/ScratchJr เขียนเป็นข้อความอธิบาย ยังไม่ได้ทดลองต่อใน Scratch จริง
