# แต่งชุดโจทย์ Bright Up Kids

## 1. Schema จริง (ห้ามเพี้ยน)

```ts
type Grade = 1 | 2 | 3 | 4 | 5 | 6;
type Subject = "math" | "thai" | "english" | "science";

interface Question {
  prompt: string;        // โจทย์
  choices: string[];     // ตัวเลือก — ใช้ 4 ตัวเสมอ
  answerIndex: number;   // ลำดับตัวเลือกที่ถูก เริ่มจาก 0 (ไม่ส่งให้เครื่องนักเรียน)
  explain?: string;      // คำอธิบายเฉลย — ขอจาก lesson-designer
}

interface Exercise {
  id: string;            // ระบบสร้างให้
  title: string;         // ชื่อชุด เห็นบนปุ่มของเด็ก
  subject: Subject;
  grade: Grade;
  topic: string;         // หัวข้อ เช่น "การบวก" — ใช้สรุปจุดอ่อนรายคน
  questions: Question[];
  published: boolean;    // ต้องเป็น false เสมอ
  createdAt: string;     // ระบบสร้างให้
}
```

ของจริงอยู่ที่ `web/src/lib/types.ts` · ตัวอย่างชุดเดิม 57 ชุดอยู่ที่ `web/src/lib/server/seed-exercises.ts`

## 2. กฎลิขสิทธิ์ (ข้อนี้ผิดแล้วเสียทั้งธุรกิจ)

สาขานี้เป็นแฟรนไชส์ **เนื้อหาแบบฝึกหัดของ HQ มีลิขสิทธิ์**

- ✅ แต่งใหม่จากหัวข้อในหลักสูตร
- ✅ ใช้โครงสร้างโจทย์มาตรฐาน (เช่น "A + B = ?") — โครงสร้างไม่มีลิขสิทธิ์
- ❌ ห้ามคัดลอกข้อความโจทย์จากหนังสือ เอกสาร HQ ข้อสอบเก่า หรือเว็บไซต์
- ❌ ห้ามแปลโจทย์จากเว็บต่างประเทศแล้วใช้ตรง ๆ
- ❌ ห้ามใช้ชื่อตัวละครหรือแบรนด์ที่มีลิขสิทธิ์ในโจทย์

**ใช้ชื่อไทยทั่วไปในโจทย์:** น้องแพรว, น้องภูมิ, น้องมะลิ, คุณครูฝน, แม่ค้า, พี่ชาย

## 3. แผนที่หัวข้อรายชั้น (ตั้งต้น — ต้องเทียบกับหลักสูตรแกนกลางก่อนใช้จริง)

> ⚠️ ตารางนี้เป็นแนวทางการทำงาน ไม่ใช่เอกสารหลักสูตรทางการ · ก่อนปล่อยชุดใหม่ ให้เทียบกับหนังสือเรียนของโรงเรียนในพื้นที่ว่าชั้นไหนเรียนอะไรจริง

| ชั้น | คณิต | ไทย | อังกฤษ | วิทย์ |
|---|---|---|---|---|
| ป.1 | จำนวน 1-100, บวกลบไม่ทด, รูปทรง | สระ พยัญชนะ คำพื้นฐาน | ตัวอักษร สี ตัวเลข คำทักทาย | ร่างกาย พืช สัตว์รอบตัว |
| ป.2 | บวกลบมีทด, สูตรคูณ 2-5, เวลา | วรรณยุกต์ คำคล้องจอง | ครอบครัว สิ่งของในห้อง คำกริยาง่าย | น้ำ อากาศ กลางวันกลางคืน |
| ป.3 | คูณหาร, เศษส่วนเบื้องต้น, หน่วยวัด | ชนิดคำ การอ่านจับใจความ | อาหาร สัตว์ จำนวนนับ ประโยคสั้น | แรง แสง เสียง ดิน |
| ป.4 | เศษส่วน ทศนิยม มุม พื้นที่ | สำนวน คำราชาศัพท์เบื้องต้น | Present Simple, คำถาม Wh- | วงจรชีวิต ระบบสุริยะ สถานะของสาร |
| ป.5 | ร้อยละ บัญญัติไตรยางศ์ ปริมาตร | การเขียนย่อหน้า คำเป็นคำตาย | Past Simple, คำคุณศัพท์เปรียบเทียบ | ระบบร่างกาย วัฏจักรน้ำ ไฟฟ้า |
| ป.6 | สมการเบื้องต้น สถิติ กราฟ | การวิเคราะห์เรื่อง โวหาร | Present Perfect, Passive เบื้องต้น | พันธุกรรม พลังงาน ระบบนิเวศ |

ค่า `topic` ให้ใช้คำสั้น ๆ ตรงกับคอลัมน์ข้างบน เช่น `"การบวก"`, `"เศษส่วน"`, `"Past Simple"` — **ถ้าหัวข้อนี้มีในคลังแล้ว ต้องสะกดให้ตรงเป๊ะ** เพราะระบบใช้สรุปจุดอ่อนรายคน

## 4. กติกาตัวลวง (ส่วนที่คนทำพลาดบ่อยสุด)

ตัวลวงที่ดี = คำตอบที่เด็กจะได้ **ถ้าคิดผิดแบบที่เด็กผิดจริง**

| วิชา | ตัวลวงที่ดี | ตัวลวงที่แย่ |
|---|---|---|
| คณิต | ลืมทด, ทดผิดหลัก, สลับบวกเป็นลบ, คลาดไป ±1 | ตัวเลขสุ่มที่ห่างมาก (เด็กตัดทิ้งได้ทันที) |
| อังกฤษ | คำที่สะกดใกล้กัน, รูปกริยาผิด tense | คำที่คนละหมวดกันชัดเจน |
| ไทย | คำที่เสียงเหมือนแต่เขียนต่าง | คำที่ไม่มีใครเลือก |
| วิทย์ | ความเข้าใจผิดที่พบบ่อยจริง | คำตอบที่ผิดอย่างไร้สาระ |

**ตรวจทุกครั้ง:**
- [ ] ตัวเลือก 4 ตัว ไม่ซ้ำกัน
- [ ] มีคำตอบถูก **ข้อเดียว** — ตัวลวงต้องไม่ถูกด้วยการตีความอีกแบบ
- [ ] `answerIndex` ชี้ตรงตำแหน่งจริง (นับจาก 0)
- [ ] ตำแหน่งคำตอบถูก **กระจาย** ไม่ใช่อยู่ตัวที่ 1 ทุกข้อ
- [ ] ความยาวตัวเลือกใกล้เคียงกัน (ตัวที่ยาวผิดปกติ = เด็กเดาได้ว่าถูก)

## 5. ขนาดและความยากของชุด

| ชั้น | จำนวนข้อ/ชุด | เวลาที่ควรใช้ |
|---|---|---|
| ป.1-2 | 8-10 | 5-8 นาที |
| ป.3-4 | 10-12 | 8-12 นาที |
| ป.5-6 | 12-15 | 10-15 นาที |

**เรียงจากง่ายไปยากในชุดเดียวกัน** — 2 ข้อแรกต้องง่ายพอที่เด็กอ่อนที่สุดจะตอบถูก (ไม่งั้นเขาเลิกทำตั้งแต่ข้อแรก)

## 6. ความยาวข้อความ

- `prompt` ป.1-3: ไม่เกิน 2 บรรทัดบนจอมือถือ 360px (~60 ตัวอักษร)
- `prompt` ป.4-6: ไม่เกิน 3 บรรทัด
- `choices` แต่ละตัว: สั้นที่สุดเท่าที่สื่อความได้
- ห้ามใช้คำศัพท์ที่เกินชั้น — ถ้าจำเป็นต้องใช้ ให้ใส่คำอธิบายในวงเล็บ

## 7. รูปแบบส่งมอบ

**ทางที่สั้นที่สุด: เติมเข้า `WRITTEN` ใน `web/src/lib/server/seed-exercises.ts`**
แต่ละข้อเป็น tuple 6 ช่อง `[โจทย์, คำตอบถูก, ตัวลวง, ตัวลวง, ตัวลวง, คำอธิบาย]`
เขียนคำตอบถูกไว้ช่องแรกเสมอ — ระบบสลับตัวเลือกให้เอง `answerIndex` จึงไม่มีทางผิด
(ชุดอังกฤษ ป.1 เทอม 2 และไวยากรณ์ ป.3-5 ใช้ช่องทางนี้ ดูเป็นตัวอย่างได้)

**ตรวจก่อนส่งทุกครั้ง:**

```bash
cd web && npm run audit:exercises && npm run test:server
```

`test:server` จะล้มถ้าตัวเลือกไม่ครบ 4 / ซ้ำ / `answerIndex` เพี้ยน / โจทย์ซ้ำในชุดเดียวกัน / `topic` สะกดไม่ตรงกับที่ใช้อยู่ · `audit:exercises` รายงานขนาดชุด ตำแหน่งคำตอบกระจุก และตัวเลือกที่ยาวผิดปกติ

หรือส่งเป็น JSON ตามรูปนี้ก็ได้:

```json
[
  {
    "title": "บวกเลขสองหลัก ชุดที่ 1",
    "subject": "math",
    "grade": 2,
    "topic": "การบวก",
    "published": false,
    "questions": [
      {
        "prompt": "23 + 14 = ?",
        "choices": ["37", "36", "38", "27"],
        "answerIndex": 0,
        "explain": "บวกหลักหน่วยก่อน 3+4=7 แล้วบวกหลักสิบ 2+1=3 ได้ 37"
      }
    ]
  }
]
```

## 8. ก่อนส่งงาน — ตรวจเองให้ครบ

- [ ] คำนวณคำตอบใหม่ทุกข้อด้วยมือ (ไม่ใช่มองผ่าน)
- [ ] ไม่มีข้อไหนที่ลอกมาจากที่อื่น
- [ ] `published: false` ทุกชุด
- [ ] `topic` สะกดตรงกับที่มีในคลัง
- [ ] ตำแหน่งคำตอบกระจาย
- [ ] แจ้งข้อที่ไม่มั่นใจให้ `content-reviewer` ทราบ

**ส่งต่อ `content-reviewer` เสมอ · ต่อให้ผ่านแล้ว ครูมนุษย์ยังต้องกดเผยแพร่เอง**
