# ด่านตรวจเนื้อหา

**ปรัชญา: ตีกลับฟรี ปล่อยผิดแพง** — เด็กที่เรียนจากเฉลยผิดจะจำผิดไปอีกหลายปี และผู้ปกครองที่เจอโจทย์ผิดจะเลิกไว้ใจทันที

---

## ด่าน 1 — ความถูกต้อง (ตรวจทุกข้อ ไม่สุ่ม)

- [ ] **คำนวณใหม่ด้วยมือทุกข้อ** — ห้ามเชื่อว่าคนแต่งคิดถูก
- [ ] `answerIndex` ชี้ไปที่ตัวเลือกที่ถูกจริง (นับจาก 0)
- [ ] มีคำตอบถูก **ข้อเดียว** — ลองตีความตัวลวงแต่ละตัวในมุมอื่น ถ้ามีทางถูกได้ = ตีกลับ
- [ ] ตัวเลือกไม่ซ้ำกัน
- [ ] คำอธิบายเฉลยสอดคล้องกับคำตอบ (เจอบ่อย: เฉลยถูก แต่คำอธิบายอธิบายอีกข้อ)
- [ ] โจทย์มีข้อมูลครบพอจะหาคำตอบได้

**วิชาวิทย์เพิ่ม:** ข้อเท็จจริงถูกตามหลักสูตรไทย ไม่ใช่ความเชื่อหรือข้อมูลล้าสมัย — ถ้าตรวจไม่ได้ ให้ตีกลับพร้อมระบุว่าต้องการแหล่งอ้างอิง

---

## ด่าน 2 — ลิขสิทธิ์ (ผิดข้อนี้กระทบทั้งธุรกิจ)

- [ ] ข้อความโจทย์ไม่ได้คัดลอกจากหนังสือ เอกสาร HQ ข้อสอบเก่า หรือเว็บ
- [ ] ไม่มีชื่อแบรนด์ ตัวการ์ตูน หรือมาสคอตของเจ้าอื่น
- [ ] ภาพไม่ได้ลอกสไตล์ที่ระบุตัวได้ของศิลปิน/แบรนด์
- [ ] ไม่ได้แปลเนื้อหาต่างประเทศมาใช้ตรง ๆ

**สัญญาณอันตราย:** สำนวนที่เป็นทางการเกินกว่าคนแต่งคนนี้จะเขียน · ชื่อตัวละครแปลก ๆ · โจทย์ที่ซับซ้อนผิดระดับ → ให้ถามที่มาก่อนผ่าน

---

## ด่าน 3 — ความเหมาะกับวัย

- [ ] คำศัพท์ไม่เกินชั้นที่ระบุ
- [ ] ความยาวอยู่ในเกณฑ์ (prompt ป.1-3 ≤ 2 บรรทัด, เฉลย ≤ 3 บรรทัด)
- [ ] ไม่มีความรุนแรง ความน่ากลัว หรือเรื่องผู้ใหญ่
- [ ] **ไม่มีการเปรียบเทียบฐานะ** (เช่น โจทย์ที่สมมติว่าเด็กมีเงินเยอะ หรือมีของแพง)
- [ ] ไม่มีอคติทางเพศ เชื้อชาติ ศาสนา รูปร่าง
- [ ] โทนเสียงกับเด็กที่ตอบผิดเป็นกำลังใจ ไม่ใช่ตำหนิ
- [ ] จำนวนข้อเหมาะกับชั้น และเรียงง่าย→ยาก (2 ข้อแรกต้องง่าย)

---

## ด่าน 4 — PDPA และความเป็นส่วนตัว

- [ ] ไม่มีชื่อจริง นามสกุล รูป หรือข้อมูลระบุตัวตนของเด็กจริง **แม้ในตัวอย่าง**
- [ ] ไม่มีชื่อโรงเรียนจริงของเด็ก
- [ ] ถ้ามีข้อมูลสถิติ ใช้รหัสนักเรียน + ชื่อเล่นเท่านั้น

---

## ด่าน 5 — โครงสร้างข้อมูล

- [ ] ตรง schema `Exercise` / `Question` (ดู skill `exercise-authoring`)
- [ ] `published: false` ทุกชุด
- [ ] `subject` เป็นหนึ่งใน `math` `thai` `english` `science`
- [ ] `grade` เป็น 1-6
- [ ] `topic` สะกดตรงกับหัวข้อเดิมในคลัง (ถ้าเป็นหัวข้อเดิม) — ตรวจด้วย grep ใน `seed-exercises.ts`
- [ ] `title` ไม่ซ้ำกับชุดที่มีอยู่
- [ ] ตำแหน่งคำตอบถูกกระจาย ไม่กองอยู่ตัวเดียว

---

## รูปแบบรายงาน

```
## ผลตรวจ: [ผ่าน / ตีกลับ]
ตรวจไป: X ชุด / Y ข้อ

### ข้อที่มีปัญหา
| ชุด | ข้อ | ด่านที่ตก | ปัญหา | ควรแก้เป็น |
|---|---|---|---|---|

### ข้อสังเกต (ไม่ถึงกับตีกลับ)
- ...

⚠️ ผ่านจาก content-reviewer ≠ เผยแพร่
ครูต้องอ่านและกดเผยแพร่เองในระบบ (ชุดทั้งหมดยังเป็น published: false)
```

## เส้นที่ห้ามข้าม

- 🚫 **ห้ามแก้เนื้อหาเอง** — ตีกลับให้เจ้าของงานแก้ ไม่งั้นงานแก้จะไม่มีใครตรวจ
- 🚫 **ห้ามผ่านเพราะ "น่าจะถูก"** หรือเพราะงานเร่ง
- 🚫 **ห้ามสุ่มตรวจ** — ชุดโจทย์ต้องตรวจทุกข้อ
